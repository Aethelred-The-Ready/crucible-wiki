# Weakening Strike
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list)<br/>
<b>Level:</b> 3<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Artistry prevents the target from using Martial Arts with a Range of Strike, and Skills requiring the use of weapons, except Weapon Proficiencies. The target may still cast Spells which are delivered as &lt;Delivery Type&gt;-Strike.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical)-Strike [Weakness](/docs/glossary/curse#weakness)" <br/>
