# Acid Wave
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Alchemy allows the Character to throw any number of packets. Any creature struck by one or more packets takes thirty(30) points of [Poison](/docs/glossary/delivery-types#poison) Acid damage.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "30 [Poison](/docs/glossary/delivery-types#poison) Acid"<br/>
