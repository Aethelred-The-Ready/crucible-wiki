# Elemental Guard
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell negates the next effect delivered as [Elemental-Strike](/docs/glossary/delivery-types#elemental) by which the target is struck.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Elemental](/docs/glossary/delivery-types#elemental) [Shield](/docs/glossary/shield)"<br/>
