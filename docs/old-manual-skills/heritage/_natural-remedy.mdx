<b>Requirements:</b> None\
Character with this Skill may spend sixty(60) seconds examining the target, role playing this examination involves checking their eyes, pallor, and other physical features while gathering ingredients from the surrounding area or their own person. At the end of the minute the Character states “Natural Remedy. Poison Dispel Poison.”. This ability is usable at will.\
The Character is able to use this Skill on themselves, and is even able to do so while they are under an effect which prevents them from using Skills.
