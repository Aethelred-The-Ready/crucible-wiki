# Unyielding Armour
<b>Cost:</b> P3 C2 T2<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> None<br/>
<b>Target:</b> Adamantine Armour or Adamantine Shield<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target Armour or [Shield](/docs/glossary/shield) with the following ability. Once per [Reset](/docs/glossary/reset), the Item can negate a single attack causing Weapon Damage or a single effect delivered as [Physical(-Strike)](/docs/glossary/delivery-types#physical). The call for this ability is "[Ward](/docs/glossary/Ward)".<br/>
