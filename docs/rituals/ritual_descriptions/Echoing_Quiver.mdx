# Echoing Quiver
<b>Cost:</b> P2 C2 T1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Quiver<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target Quiver with the following ability. Once per [Reset](/docs/glossary/reset), the wielder may [Echo](/docs/glossary/echo) a single Martial Art delivered by one, or more, Archery Packet(s). The Call for this ability is "Echo &lt;Delivery Verbal&gt;"<br/>
