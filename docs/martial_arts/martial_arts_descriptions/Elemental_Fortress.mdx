# Elemental Fortress
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Artistry grants the Caster the ability to negate a single effect delivered as [Elemental](/docs/glossary/delivery-types#elemental)(-Strike) by which the target is struck. The target's player chooses when this ability activates.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Elemental](/docs/glossary/delivery-types#elemental) [Ward](/docs/glossary/Ward)"<br/>
