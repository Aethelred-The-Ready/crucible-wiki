# Master's Touch
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This Invocation causes the target Masterwork item to become [Indestructible](/docs/glossary/indestructible) and immune to [Break](/docs/glossary/break) and [Destroy](/docs/glossary/destroy). This effect ends if the item leaves the Caster's possession.<br/>
