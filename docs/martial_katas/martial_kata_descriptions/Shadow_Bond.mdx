# Shadow Bond
<b>School:</b> [Duelist](/docs/martial_arts/duelist_list), [Slayer](/docs/martial_arts/slayer_list)<br/>
<b>Effect:</b> This Kata increases the Character's Weapon Damage, when behind their target and able to see both their target's shoulder blades, with the chosen weapon by two(2). This Kata may be performed more than once but each additional effect must target another weapon. This effect does not stack with any other Kata which increases Weapon Damage.<br/>
