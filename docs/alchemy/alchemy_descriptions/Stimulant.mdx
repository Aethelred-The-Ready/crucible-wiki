# Stimulant
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Alchemy grants the target a single use of the Dodge Skill, allowing them to avoid a single effect, delivered by weapon or packet.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Imbue Skill](/docs/glossary/imbue-skill): Dodge"<br/>
