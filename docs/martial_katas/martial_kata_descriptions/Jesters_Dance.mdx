# Jester's Dance
<b>School:</b> [Duelist](/docs/martial_arts/duelist_list)<br/>
<b>Effect:</b> This Kata grants the Character five(5) Charges of this ability. The Character can expend one(1) Charge to [Dodge](/docs/combat/defences#dodge) a single attack delivered by Weapon or Packet. Once the first charge has been used the Character has ten(10) seconds to use another charge or all remaining Charges are lost and this effect ends.<br/>
