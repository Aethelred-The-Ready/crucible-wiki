# Memorise Ritual
<b>Requirements:</b> [Ritual Magic](/docs/skills/magic/Ritual_Magic.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character to perform, without the need of a Ritual [Diagnose](/docs/skills/crafting-skills/scroll), a single [Ritual Magic](/docs/rituals) of their choice. This Skill cannot be used to learn any Ritual Magic which is marked as Limited in its description.<br/>
