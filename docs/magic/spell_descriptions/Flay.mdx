# Flay
<b>School:</b> [Affliction](../affliction_list), [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Spell instantly reduces the value of any [Natural Armour](/docs/equipment/non-physical-armour) worn by the target to zero(0).<br/>
<b>Incantation:</b> "I Curse you to be Flayed."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Breach](/docs/glossary/breach) [Natural Armour](/docs/equipment/non-physical-armour)"<br/>
