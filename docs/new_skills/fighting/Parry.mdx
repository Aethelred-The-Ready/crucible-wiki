# Parry
<b>Requirements:</b> [Weapon Training](/docs/new_skills/fighting/Weapon_Training.mdx) 2 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may negate any attack delivered, by weapon or packet, as [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) or [Physical](/docs/glossary/delivery-types#physical) by which they are struck. In order to use this Skill the Character must have a Weapon or [Shield](/docs/glossary/shield) in hand. This ability cannot be used if the Character is under an effect which prevents the Character from using Weapons or if the Item is [Fumble](/docs/glossary/curse#fumble)d. Effects delivered as [Arcane-Strike](/docs/glossary/delivery-types#arcane) cannot be avoided by this, or any other, ability. The call for this ability is "Parry". If the Character has the [Body](/docs/glossary/body)guard Skill they can use this ability to negate an applicable attack which strikes the target of their Bodyguard Skill when they are within their Weapon's reach.<br/>
