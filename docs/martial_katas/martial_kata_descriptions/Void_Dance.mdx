# Void Dance
<b>School:</b> [Duelist](/docs/martial_arts/duelist_list)<br/>
<b>Effect:</b> This Kata increases the Character's Wear Point total by ten(10) to a maximum of fifty(50). Additionally, the value of any [Avoidance Armour](/docs/equipment/non-physical-armour) the Character has is increased by ten(10). This effect stacks with all other effects which Reinforce Avoidance Armour.<br/>
