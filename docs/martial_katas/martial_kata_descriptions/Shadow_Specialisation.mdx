# Shadow Specialisation
<b>School:</b> [Duelist](/docs/martial_arts/martial_arts#school), [Slayer](/docs/martial_arts/martial_arts#school)<br/>
<b>Effect:</b> This Kata increases the Character's Weapon Damage, when behind their target and able to see both their target's shoulder blades, with the chosen weapon by four(4). Once the Character has performed this Kata they are unable to use Martial Arts with any other weapon until this effect ends, or the Character casts this effect again, choosing a new weapon. This effect does not stack with any other Kata which increases Weapon Damage.<br/>
