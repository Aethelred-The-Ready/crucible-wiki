# Healer's Touch
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 0<br/>
<b>Range:</b> Self and Touch<br/>
<b>Duration:</b> Charged (5)<br/>
<b>Effect:</b> This Cantrip grants the Caster five(5) charges of this effect. The Caster may expend one charge to deliver, by [Contingency](/docs/glossary/delivery-types#touch), one(1) point of [Magic](/docs/glossary/delivery-types#magic) [Healing](/docs/glossary/healing). As a Cantrip, this effect can be used once, afterwards the Character must Rest in order to regain its use.<br/>
<b>Incantation:</b> None<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "1 [Magic](/docs/glossary/delivery-types#magic) [Healing](/docs/glossary/healing)"<br/>
