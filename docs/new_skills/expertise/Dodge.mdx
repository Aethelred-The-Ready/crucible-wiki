# Dodge
<b>Requirements:</b> [Stealth Training](/docs/new_skills/expertise/Stealth_Training.mdx) 2 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may negate any effect delivered by Weapon or Packet by which they are struck. Effects delivered as [Arcane-Strike](/docs/glossary/delivery-types#arcane) cannot be avoided by this, or any other, ability. The call for this ability is "Dodge".<br/>
