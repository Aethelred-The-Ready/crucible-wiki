# Archer's Quiet
<b>School:</b> [Duelist](/docs/martial_arts/duelist_list)<br/>
<b>Effect:</b> This Kata grants the Character one(1) Charge of this ability. The Character can expend one(1) Charge to activate this ability. Upon activating this ability the Character may use the Weapon Type: Massive for all Archery attacks. This effect ends if the Character moves from where they were standing when they activated this ability.<br/>
