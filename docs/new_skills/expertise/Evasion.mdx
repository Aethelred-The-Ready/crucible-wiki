# Evasion
<b>Requirements:</b> [Dodge](/docs/new_skills/expertise/Dodge.mdx) 3 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may negate any effect by which they would be affected. Effects delivered as [Arcane](/docs/glossary/delivery-types#arcane)(-Strike) cannot be avoided by this, or any other, ability. The call for this ability is "Evasion".<br/>
