# Word of Recall
<b>Cost:</b> P4 C1 S1 T1 + P1 per additional target<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Conjuration](/docs/magic/conjuration_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Circle and The Caster and One additional target per component<br/>
<b>Duration:</b> Event [Cannot be Extended]<br/>
<b>Effect:</b> As part of casting this Ritual the [Caster](/docs/rituals/ritual_glossary#Caster) chooses a word. The target [Circle](/docs/rituals/ritual_glossary#Circle) becomes the Destination. At any time during the event a target may speak the chosen word. They will immediately gain the benefits of a [Magic](/docs/glossary/delivery-types#magic) [Teleport](/docs/glossary/teleport) to the Circle in which this Ritual was cast. Though the Character can use this ability while under an effect that would keep them from using Skills, they must be able to speak to trigger this effect. This effect cannot be Extended and ends with the Event during which it was cast. Upon arrival, all targets appear at the edge of the area with the phrase "Magic Teleport". This effect ends once it has been triggered. <br/>
