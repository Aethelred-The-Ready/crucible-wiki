# Extend Ritual, Greater
<b>Cost:</b> P4 C2 T2 (Requires one P2 or P4)<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> All<br/>
<b>Target:</b> Any Ritual Effect or Concert.<br/>
<b>Duration:</b> Two(2) Years<br/>
<b>Effect:</b> When cast as the last Ritual in a Ritual Concert, this Ritual extends the duration of all valid Ritual effects in the current target Ritual Concert to two(2) years. This effect consumes one(1) of the item's Ritual effect slots.<br/>
