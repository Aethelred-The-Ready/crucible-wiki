# Master's Secret
<b>Requirements:</b> Grand Master [Smithing](/docs/skills/crafting/Smithing.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character to perform, without the need of a Schematic, a single Ritual Smithing of their choice. This Skill cannot be used to learn any Ritual Smithing which is marked as "Limited" in its description.<br/>
