# Transmuting Weapon
<b>Cost:</b> P2 C3 T1<br/>
<b>Type:</b> Alchemy<br/>
<b>School:</b> None<br/>
<b>Target:</b> Item<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target item with the following ability. The wielder of the target weapon to change its Weapon Type to any of the following; Normal, [Iron](/docs/equipment/special-materials), or [Silver](/docs/equipment/special-materials). The process of changing Weapon Types takes one(1) minute, but can be done at will. If the item is under a Ritual effect which only affects weapons made of a Special Material, the effect cannot be used unless the weapon is the corresponding type. Any effects which are suppressed still count against the number of Ritual Effects on the target item.<br/>
