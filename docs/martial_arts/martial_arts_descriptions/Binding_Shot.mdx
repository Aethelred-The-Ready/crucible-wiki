# Binding Shot
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Binding](/docs/glossary/binding) Artistry can be used only with a [Avoidance Armour](/docs/equipment/weapons) or the [Dodge Skill](/docs/skills/fighting/archery). This effect forces the target's arms to their sides and keeps them there throughout its duration. The creature cannot use any Skill which requires the use of their arms such as using weapons or casting Spells.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical-Strike](/docs/glossary/delivery-types#physical) [Bind](/docs/glossary/binding#bind)"<br/>
