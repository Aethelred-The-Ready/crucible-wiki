# Purifying Armour
<b>Cost:</b> P2 C1 S2<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> None<br/>
<b>Target:</b> Silver Armour or Silver Shield<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target armour or shield with the following ability. Once per [Reset](/docs/glossary/reset), the Item can negate a single effect with a duration other than instant. The call for this ability is "[Ward](/docs/glossary/Ward)".<br/>
