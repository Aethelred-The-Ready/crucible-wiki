# Binding Shield
<b>School:</b> [Conjuration](../conjuration_list), [Protection](../protection_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell negates the next [Binding](/docs/glossary/binding) effect by which the target is struck. The following effects are Binding; Bind, [Confine](/docs/glossary/binding#confine), [Pin](/docs/glossary/binding#pin), and [Web](/docs/glossary/binding#web).<br/>
<b>Incantation:</b> "I grant you the protection of a Binding Shield."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Binding](/docs/glossary/binding) [Shield](/docs/glossary/shield)"<br/>
