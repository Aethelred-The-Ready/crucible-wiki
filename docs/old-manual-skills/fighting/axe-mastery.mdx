# Axe Mastery
import Skill from '../skill.tsx'

<b>Requirements:</b> None\
The Character gains the ability to wield all [Axes](../../equipment/weapons) in combat. When wielding a Two-Handed Weapon, the Character may block attacks while holding the Weapon with one hand but cannot attack, or use the Weapon to deliver any Skill, until they have both hands on the Two-Handed Weapon. At the time this Skill is bought, the Character may “sell back” any Skills which are included in its benefit.
