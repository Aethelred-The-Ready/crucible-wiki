# Standard Effects

More information about each Effect can be found in the Glossary or the link from this page

This page summarizes the most important aspects of Effects that all Players should be familiar with.

### [Aegis](/docs/glossary/aegis)
This effect, typically, renders the user Immune
to Weapon Damage and effects delivered as [&lt;Effect>-Strikes](/docs/glossary/delivery-types#strike). An Aegis is represented by the Character crossing both arms over their upper chest.

### [Alarm](/docs/glossary/alarm) / [Safeguard](/docs/glossary/safeguard) / [Sanctuary](/docs/glossary/sanctuary)
If a Character is not invested in a room marked with an "A" they, or a Marshal, must knock loudly for ten(10) seconds . The intruder may defend themselves while knocking. 
If a Container or Room is marked with an "S" or a "W" a Character not invested will not be able to open it through mundane means. See the descriptions of these effects for more information.

### Ambush &lt;#>
In order to use some Skills, a Character must be standing behind
their target and able to see both shoulder blades. This
ability allows a Character to ignore this requirement a
number of times equal to the Character's Charges of
Ambush. This ability also allows a Character to use the
damage bonus from their Stealth Training regardless of
their position around their target. Each time the
Character successfully lands any valid hit on a target, or
uses any other weapon delivered effect, one(1) charge
is consumed. At the [end of Combat](/docs/glossary/combat), all remaining
Charges are lost.

### Berserk
This effect forces the Character into an
insane killing frenzy forcing them to attack everyone
around them to the best of their Player’s ability using the
most effective means at their disposal.

### Bind
This [Binding](/docs/glossary/binding) effect forces the target's arms to
their sides and keeps them there throughout its duration.
The creature cannot use any Skill which requires the
use of their arms such as using weapons or casting
spells. 

### Blind
This [Curse](/docs/glossary/curse) effect prevents the target from using
any ranged attacks including thrown weapon and packet
attacks

### &lt;#> &lt;Deliver Type> Body
This effect causes damage
directly to the target’s [Hit Points](/docs/combat/hit-points) bypassing any [Armour Points](/docs/combat/armour-points) the Character may have. If the Character has any
Fortification Points the damage is subtracted from these
before it causes Hit Points damage.

### Breach
This effect instantly
reduces any Armour Points the Character has from
the chosen Armour Type to zero(0). It does not
prevent the armour from being [Refit](#refit) normally.

### Break &lt;Item>
This effect Breaks the target item. A
Broken item cannot be used until it is Repaired.
If the target has multiple items in their possession
which match the description of the item designated by
the user it is the target chooses which of their items are
affected.

### Calm
This [Compulsion](/docs/glossary/compulsion) effect causes the target to
enter an extremely calm and tranquil state. The target
cannot attack themselves or any other creature
though they will not ignore danger. This effect ends if
the target is attacked.

### Charm
This [Compulsion](/docs/glossary/compulsion) effect causes the target to
view the caster as a trusted friend listening to their
suggestions and not attacking them. This does not grant
the caster any control over the target. This effect ends if
the caster attacks the target.

### Cleanse
This effect removes all harmful effects from
the target that would be removed by their Death. It is the
decision of the target’s Player as to which effects are
harmful.

### Confine
This [Binding](/docs/glossary/binding) effect forces the target's arms to
their sides and immobilises the target preventing them
from moving, being moved, or using any Skills while in effect. The target may
still speak.

### Cowardice
This [Compulsion](/docs/glossary/compulsion) effect prevents the target
from using any non-ranged weapon attacks including
effects which are delivered as &lt;Effect>-Strike. 

### Cripple
This [Curse](/docs/glossary/curse) effect affects a limb of the target. A
Crippled arm cannot be used for any Skills and cannot
hold any items. A Crippled leg cannot be used to walk
and prevents the target from moving faster than a slow,
limping walking pace. The target cannot hop. If both legs
are Crippled the target can only kneel in place. Unlike
most effects, this one stacks with each new Cripple
effect affecting a new limb until the Character has no
remaining limbs.

### [Cunning &lt;#>](/docs/glossary/cunning)
This ability grants the Character &lt;#>
additional points of Weapon Damage when they are
standing behind their target and able to see both of
their shoulder blades. This effect stacks with all
similar effects which increase weapon damage but
multiple effects which grant Cunning do not stack
unless explicitly states otherwise.

### Death
This effect instantly causes a living creature
to enter its [Death Count](/docs/combat/states-of-living#dead).
