# Corrosion
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell allows the Caster to deliver a [Break](/docs/glossary/break) effect by Touch. An item which is Broken cannot be used until it is [Repair](/docs/glossary/repair)ed.<br/>
<b>Incantation:</b> "I alter this form to be Corroded."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Break](/docs/glossary/break) &lt;Item&gt;"<br/>
