# Invoker
<b>Requirements:</b> Level 5 Alchemy Slot, Level 5 [Spell Slot](/docs/new_skills/magic/Spell_Slot.mdx), or [Smithing](/docs/new_skills/crafting/Smithing.mdx) 5.<br/>
<b>Benefit:</b> Once per Day, the Character may perform a single Invocation of any type for which the meet this Skill's Requirements. Level 5 Alchemy Slots allow a single Alchemy Invocation. Level 5 Spell Slots allow a Magic Invocation. Five(5) Ranks in the Skill Smithing allows a Smithing Invocation. A Character who meets multiple requirements does not gain the ability to perform multiple Invocations with this Skill but expands their options for the one(1) they may perform. This Skill does not count towards the Requirements of any other Skills or abilities.<br/>
