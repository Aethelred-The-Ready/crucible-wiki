# Smithing, Grand Master
<b>Requirements:</b> Master [Smithing](/docs/new_skills/crafting/Smithing.mdx), Smithing 20<br/>
<b>Benefit:</b> This Skill grants the Character the ability to cast Ritual Smithing. Upon gaining this Skill the Character can act as the Primary Caster, or as a Secondary Caster, for any Ritual Smithing. Additionally, the Character gains the ability to cast Invocations. See Chapter 8: Rituals for more information on casting Ritual Smithing and Invocations.<br/>
