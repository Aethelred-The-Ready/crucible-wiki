# Create Wand
<b>Requirements:</b> [Create Scroll](/docs/skills/crafting/Create_Scroll.mdx) 10<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may expend a single Spell Slot to create a Wand containing a Spell, the Character can cast, with a Range of [Contingency](/docs/glossary/delivery-types#touch) or Packet, of the same level as the expended Spell Slot. Once a Spell has been put into a Wand, its creator may use the wand to deliver the stored Spell up to five(5) times.

A Wand must be marked with the Spell it contains, as well as the number of charges it contains, and must measure between 10 and 100cm.

In order to use this Skill the Character must have access to a [Diagnose](/docs/skills/crafting-skills/scroll) Laboratory. All Wands expire at the end of the Event.<br/>
