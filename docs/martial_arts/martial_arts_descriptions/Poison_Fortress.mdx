# Poison Fortress
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Artistry grants the Caster a [Ward](/docs/glossary/Ward) allowing them to negate a single effect delivered as [Poison(-Strike)](/docs/glossary/delivery-types#poison) by which they are struck. The Caster chooses when to activate this ability.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Poison](/docs/glossary/delivery-types#poison) [Ward](/docs/glossary/Ward)"<br/>
