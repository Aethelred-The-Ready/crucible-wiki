# Martial Secret
<b>Requirements:</b> [Martial Kata](/docs/skills/fighting/Martial_Kata.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character to perform, without the need of a Martial Treatise, a single Martial Kata of their choice. This Skill cannot be used to learn any Martial Kata which is marked as Limited in its description.<br/>
