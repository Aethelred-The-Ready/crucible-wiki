# Poison Ward
<b>School:</b> [Protection](../protection_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Charged (1)<br/>
<b>Effect:</b> This Spell grants the target a [Ward](/docs/glossary/Ward) allowing them to negate a single effect delivered as Poison(- Strike) by which they are struck. The target chooses when to activate this ability.<br/>
<b>Incantation:</b> "I grant you the protection of a Poison Ward."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Poison](/docs/glossary/delivery-types#poison) [Ward](/docs/glossary/Ward)"<br/>
