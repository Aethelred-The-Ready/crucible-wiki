# Ritual Component

A Component is an item which is
necessary for casting Rituals. Components have
seven types; Power, Creation, Destruction,
Elemental, Spirit, Time and Void. Components are
expended to pay the Component cost listed on each
Ritual.

 Void Components are used by some Rituals but
can also be used in place of any other Component
type in a Ritual. Should the number of Void
Components used meet or exceed one-half the total
number of components needed in the base Ritual
cost, the Ritual becomes Unstable.

 In order to Identify components the Character must
possess one(1), or more, of the following Skills;
Alkahestry, Grand Master Smithing, Ritual Magic. A
Character without at least one of these Skills is able
to recognize that it is a Component, but not the type
or Strength. Some Ritual Components require the
Identify effect or knowledge of the specific component
to reveal all of their properties.

A Character that cannot identify a Ritual Component can only know the descriptive information on a Ritual Component's tag

## Identifying Ritual Components
If you are able to Identify a ritual component, because you have one of the skills allowing you to do so, the following information will be helpful.

All Strength 1 Components are small bags with an object and a tag. It is not a valid Ritual Component without all three items, so ensure that the bag is tightly closed and tied. 

Strength 2 Components appear as a sealed glass phial with an object inside.

Strength 4 Components appear as Strength 2 Components but the seal will have gold in it.

Special Components may or may not have a distinguishing mark about them

With all Ritual Components, the colour of the Seal indicates the type
|Type|Colour|
|---|---|
|Power|Red|
|Creation|Green|
|Destruction|Black|
|Elemental|Blue|
|Spirit|White|
|Time|Yellow|
|Void|Purple|


## Special Component
 This refers to a Special
Component which needed to perform certain Ritual
effects. Special Components can be Identified to
discover any Ritual to which they are applicable. For
example, a Component may be an E4, but can also
be used as the Special Component needed to create
a Planar Gate to the plane of Fire. Some Special
Components have special effects which modify the
performance of a Ritual. For example, there is a
component which provides all Power needed for a
Ritual, but causes the Ritual to become Unstable. 

When using a Special Component for a Ritual that requires it, it does not contribute its own Strength to the Ritual. I.e. a Hangman's Nail that is also a D4 does not contribute 4 Destruction Strength when used to cast Annihilation
