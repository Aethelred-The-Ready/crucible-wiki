# Simple Weapon
import Skill from '../skill.tsx'

<b>Requirements:</b> None\
The Character gains the ability to wield all
[Simple Weapons](../../equipment/simple-weapon) in combat. A Simple Weapon can
only be used to block and can never be used to
attack but can be used to deliver a Killing Blow.
