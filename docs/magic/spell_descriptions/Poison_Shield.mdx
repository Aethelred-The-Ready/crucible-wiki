# Poison Shield
<b>School:</b> [Protection](../protection_list), [Restoration](../restoration_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell grants the target a [Shield](/docs/glossary/shield) against the next effect delivered as [Poison-Strike](/docs/glossary/delivery-types#poison) by which they are struck.<br/>
<b>Incantation:</b> "I grant you the protection of a Poison Shield."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Poison](/docs/glossary/delivery-types#poison) [Shield](/docs/glossary/shield)"<br/>
