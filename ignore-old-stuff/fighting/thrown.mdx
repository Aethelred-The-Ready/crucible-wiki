# Thrown
import Skill from '../skill.tsx'

<b>Requirements:</b> None\
The Character gains the ability to wield a
[Thrown](../../equipment/thrown) Weapons in combat. Thrown Weapons may
never possess a core and must be sculpted only
using foam. Additionally, never aim for illegal areas
including the head, groin and face.
