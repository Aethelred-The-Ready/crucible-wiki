# Escape
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry, which can be Cast without the need for a free hand, instantly removes all [Binding](/docs/glossary/binding) effects from the Caster. The following effects are Binding; Bind, [Confine](/docs/glossary/binding#confine), [Pin](/docs/glossary/binding#pin), and [Web](/docs/glossary/binding#web). Please note that Confine prevents the target from using Skills and so this ability normally cannot be used while under its effects.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Dispel](/docs/glossary/dispel) [Binding](/docs/glossary/binding)"<br/>
