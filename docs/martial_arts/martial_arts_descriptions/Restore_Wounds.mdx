# Restore Wounds
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry causes ten(10) points of [Physical](/docs/glossary/delivery-types#physical) [Healing](/docs/glossary/healing) to the target. Any healing above the Character's maximum is lost.<br/>
