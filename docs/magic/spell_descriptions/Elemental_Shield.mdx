# Elemental Shield
<b>School:</b> [Conjuration](../conjuration_list), [Protection](../protection_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell negates the next effect delivered as [Elemental](/docs/glossary/delivery-types#elemental)(-Strike) by which the target is struck.<br/>
<b>Incantation:</b> "I grant you the protection of an Elemental Shield."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Elemental](/docs/glossary/delivery-types#elemental) [Shield](/docs/glossary/shield)"<br/>
