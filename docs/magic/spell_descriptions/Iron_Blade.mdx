# Iron Blade
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Charged (1)<br/>
<b>Effect:</b> This Spell allows the target to use the Weapon Type: [Iron](/docs/equipment/special-materials) against a single target until the end of Combat.<br/>
<b>Incantation:</b> "I grant you the power of an Iron Blade."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Iron](/docs/equipment/special-materials) [Aura](/docs/glossary/aura)"<br/>
