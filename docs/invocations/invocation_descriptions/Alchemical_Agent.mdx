# Alchemical Agent
<b>Type:</b> Alchemy<br/>
<b>Duration:</b> Charged (5)<br/>
<b>Effect:</b> Upon casting this [Invocation](/docs/invocations) the Caster chooses one of the following elements; Acid, Fire, Ice, Lightning, or Stone. This Invocation grants the Character five(5) Charges. The Character may spend one(1) Charge to deliver a packet attack causing twenty(20) points of [Physical](/docs/glossary/delivery-types#physical) damage of the chosen element.<br/>
