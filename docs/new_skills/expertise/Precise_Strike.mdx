# Precise Strike
<b>Requirements:</b> [Stealth Training](/docs/new_skills/expertise/Stealth_Training.mdx) 2 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver an attack causing "20 [Physical](/docs/glossary/delivery-types#physical)-Strike &lt;Weapon Type&gt;" damage. In order to use this Skill the Character must be standing behind their target and able to see both of their shoulder blades. This ability is also usable if the Character expends a charge from any [Ambush](/docs/glossary/ambush) effect they have on themselves.<br/>
