# Tribute
<b>Type:</b> All<br/>
<b>Duration:</b> Charged (1)<br/>
<b>Effect:</b> This Invocation grants the Character one(1) Charge. The Character may spend one(1) Charge to reduce the number of Components of a particular type needed to cast a Ritual Effect of the same type as this Invocation by one(1), to a minimum of one(1). For example, when used as a Smithing Invocation this ability can reduce the number of Power Components needed by any Ritual Smithing effect by one(1). No Ritual can be targeted by this effect, for a particular Component Type, more than once.<br/>
