# Dance of the Dragon
<b>School:</b> [Slayer](/docs/martial_arts/martial_arts#school)<br/>
<b>Effect:</b> This Kata grants the Character five(5) Charges of this ability. The Character can expend one(1) Charge to deliver an attack causing "50 [Physical-Strike](/docs/glossary/delivery-types#physical) &lt;Weapon Type&gt;". Once the first charge has been used the Character has ten(10) seconds to use another charge or all remaining Charges are lost and this effect ends.<br/>
