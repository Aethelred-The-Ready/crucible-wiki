# Disintegrate
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell [Vanquish](/docs/glossary/vanquish)es the target creature. A Vanquished creature instantly begins Bleeding Out. Some powerful creatures may not be Vanquished but are significantly damaged by this Spell. The Caster must specify the type of creature being targeted by this spell. The valid options are; Abomination, Animal, Construct, Draconian, Elemental, Fae, Humanoid, Hybrid, Insectoid, Plant, Slime, Spirit and Undead.<br/>
<b>Incantation:</b> "I alter this form to be Disintegrated."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Vanquish](/docs/glossary/vanquish) &lt;Creature Type&gt;"<br/>
