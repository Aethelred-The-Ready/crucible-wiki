# Spy
<b>Requirements:</b> <br/>
<b>Benefit:</b> A Character with this Skill is in the know about many secrets. At the start of each Event, the Player receives a rumour sheet. If the Character has the Open Lock Skill, they reduce the time needed to disarm a Trap to ten(10) seconds. If the Trap has a limited number of tries, they gain one(1) additional attempt.<br/>
