# Break
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 3<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell [Break](/docs/glossary/break)s the target item. A Broken item cannot be used until it is [Repair](/docs/glossary/repair)ed. Certain creatures, such as Constructs, may be damaged by this Spell. If the target has multiple items in their possession which match the description of the item designated by the Caster it is the target who chooses which of their items are affected. The target cannot choose an item which is [Indestructible](/docs/glossary/indestructible) unless it is the only item they have which matches that description.<br/>
<b>Incantation:</b> "I alter this form to be Broken."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Break](/docs/glossary/break) &lt;Item&gt;"<br/>
