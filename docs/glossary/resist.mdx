---
title: "Resist <Delivery Type/Effect>"
---
This ability may be
activated by the Character to negate a single effect to
which it is applicable. A Resist cannot be used to
negate any effect which is delivered as Piercing
regardless of the examples which follow.. For
example a Resist Poison can negate any effect which
is delivered as Poison(-Strike). A Resist Compulsion
can negate any effect which causes a Compulsion
effect regardless of delivery type. A Resist
Break/Destroy can negate any effect which causes
either a Destroy or Break effect. The Resist Perfect
ability applies to all possible effects. The call for this
ability is “Resist &lt;Effect>”.
