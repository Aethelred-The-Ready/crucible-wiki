# Penance
import Skill from '../skill.tsx'

<b>Requirements:</b> Level 7 Martial Art Slot or Weapon Training 5\
Once per Reset, for every time this Skill is
bought, as long as the Character has at least one(1)
Armour Point of Physical Armour available they may
expend all remaining Physical Armour Points to grant
themselves a “Physical Dispel Curse” effect. The call
for this ability is “Absorb. Physical Dispel Curse”. This
ability may be used event if the Character is under an
effect which prevents them from using Skills such as
Drain or Paralysis.
