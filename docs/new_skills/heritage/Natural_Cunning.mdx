# Natural Cunning
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains [Cunning](/docs/glossary/cunning) 2, increasing their Weapon Damage, when standing behind their target and able to see both shoulder blades, by two(2). This Skill does not count as a prerequisite for any other Skill. The Cunning from this Skill stacks with that granted by all effects including Spells.<br/>
