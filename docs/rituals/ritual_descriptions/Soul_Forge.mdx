# Soul Forge
<b>Cost:</b> P3 S1 T1 (See Text)<br/>
<b>Type:</b> Alchemy, Magic<br/>
<b>School:</b> [Restoration](/docs/magic/restoration_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Spirit<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Ritual allows the target to re-spend all Skill Points. This Ritual should be cast no more than once per year. Any casting beyond this limit doubles the number of components needed for each additional casting until the target goes one(1) year without being affected by this Ritual. This increase stacks each additional time the target is affected by this Ritual Effect. This means that if this Ritual is cast three times on the same target, the cost for a fourth casting would be eight(8) times the base [Component](/docs/rituals/ritual_glossary#Component) cost.<br/>
