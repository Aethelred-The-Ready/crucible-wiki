# Create Potion
<b>Requirements:</b> Level 1 Spell or Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may expend a single Spell or Alchemy Slot to create a [Diagnose](/docs/skills/crafting-skills/potion) containing a Technique, the Character can cast, with a Range of Touch or Packet, of the same level as the expended Technique Slot. Once a Technique has been put into a Potion, any Character may imbibe the Potion, a process taking a three(3)-count, to receive the effects of the stored Technique. A consumed Potion follows all rules for a Touch Cast Technique. Each Potion is usable only once.

When a Technique has multiple effects, such as Blood Bolt, the Character must choose which of the effects are contained within the Potion.

A Potion must be marked with the Technique it contains, as well as the Delivery Verbal, and must be a container which appears to hold twenty(20) to one- hundred(100) millilitres of liquid. Though the physical representation of each Potion may be reused, each Potion is usable only once.

If the Character has access to a Potion Laboratory they may instead create two(2) Potions for each consumed Technique Slot. All Potions expire at the end of the Event.<br/>
