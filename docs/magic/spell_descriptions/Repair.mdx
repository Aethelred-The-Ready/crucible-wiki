# Repair
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell instantly [Repair](/docs/glossary/repair)s a single item touched, and named, by the Caster.<br/>
<b>Incantation:</b> "I alter this form to be Repaired."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Repair](/docs/glossary/repair) &lt;Item&gt;"<br/>
