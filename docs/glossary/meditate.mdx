# Meditate (aka Meditation)
This is a special
sixty(60)-second Count where the Character recovers
all Skills which failed to strike any target or were
negated by the Defensive Abilities: Immunity, Resist
and Ward. This also includes any abilities which
explicitly state they can be recovered by Meditating.
Regardless of how many Skills the Character is
recovering, the Character needs to Meditate only
once to recover all of them. Meditating is interrupted if
the Character is struck by any effect, other than
Touch Casting, the Character uses any Skills, or
enters a state where they are unable to use Skills.

The Clarity effect grants the Character the benefit of
Meditating instantly.
