# Arcane Armour
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains five(5) points of [Arcane Armour](/docs/equipment/non-physical-armour) for each time this Skill is bought. A Character is still limited by their Wear Total which limits the maximum number of Armour Points of any type from which the Character may benefit. Arcane Armour is represented by the Character wearing a number of Runes equal to the total Armour Point value of the armour divided by ten(10), rounded up. These runes must be represented by and inscribed upon worn accessories which are visible on the Character. If the Character is under an effect which prevents them from using Skills, such as the [Drain](/docs/glossary/curse#drain) effect, they are unable to [Refit](/docs/glossary/refit) this armour using the Refit Armour counted action until that effect ends.<br/>
