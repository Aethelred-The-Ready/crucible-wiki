# Lightning Bolt
<b>School:</b> [Conjuration](../conjuration_list)<br/>
<b>Level:</b> 3<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell allows the Caster to throw a packet attack causing ten(10) points of [Piercing](/docs/glossary/delivery-types#piercing) [Magic](/docs/glossary/delivery-types#magic) Lightning damage.<br/>
<b>Incantation:</b> "I Conjure a Lightning Bolt."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "10 [Piercing](/docs/glossary/delivery-types#piercing) [Magic](/docs/glossary/delivery-types#magic) Lightning"<br/>
