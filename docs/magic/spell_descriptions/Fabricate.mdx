# Fabricate
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell can create any mundane item such as a weapon or suit of armour. It cannot be used to create an item with any special properties such as a silvered weapon or enhanced armour. The player must provide the physical representation of any item created by this Spell. This Spell cannot be used to create any item of value such as gold, silver, gems or other precious materials. Nor can it be used to create items with supernatural qualities such as Ritual Components. Any attempt to create such items results in worthless duplicates such as brazen coins, coloured glass or materials of poor quality.<br/>
<b>Incantation:</b> "I alter this form to be Fabricated."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Fabricate](/docs/glossary/fabricate) &lt;Item&gt;"<br/>
