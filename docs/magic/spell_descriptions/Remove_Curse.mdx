# Remove Curse
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell removes, from the target, a single [Curse](/docs/glossary/curse) effect. If the target is suffering from multiple Curse effects, it is up to the target to choose which is removed.<br/>
<b>Incantation:</b> "I call upon the Dusk to Remove Curse."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Remove](/docs/glossary/remove) [Curse](/docs/glossary/curse)"<br/>
