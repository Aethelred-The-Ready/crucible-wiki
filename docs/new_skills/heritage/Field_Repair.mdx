# Field Repair
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character may, on a sixty(60)-count, [Repair](/docs/glossary/repair) any number of mundane items without the use of a Portable Forge or expending any levels of Smithing. Once this ability is used, the Character cannot use it again until they return to Town and Rest to acquire replacement materials and maintain their tools, a process requiring access to a Forge and five(5) minutes. See page 66 for more information on Smithing abilities. If the Character has the Tinkerer Sub-Skill, they may use this ability an additional time before needing to Rest.<br/>
