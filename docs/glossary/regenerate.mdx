# Regenerate

This effect causes the target to, after a
sixty(60)-count, regain all lost [Hit Points](/docs/glossary/hit-points).
Regeneration comes in many forms with some
creatures being interrupted if they take any damage,
particular type of damage, are Killing Blowed, and so
on. There are even some creatures able to
Regenerate from Death requiring special methods to
kill. Regeneration is always visible and the target
should announce, in a normal speaking voice, “Visibly
Regenerating” every ten(10) seconds. A small
number of creatures have the ability to Regenerate in
less than a sixty(60)-count but these are very rare.
