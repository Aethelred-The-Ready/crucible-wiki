# Create Bane
<b>Cost:</b> Varies<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Affliction](/docs/magic/affliction_list)<br/>
<b>Target:</b> Any Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual creates a Bane of the type specified by the [Diagnose](/docs/skills/crafting-skills/scroll). When used to deliver a Killing Blow, the Bane causes the creature to immediately die and seek Resurrection. Banes have additional effects based on the Scroll. Eg. Bane of Vampires: 1/Ever [Arcane](/docs/glossary/delivery-types#arcane) Solidify<br/>
