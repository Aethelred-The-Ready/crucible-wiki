# Bloodthirst
<b>School:</b> [Duelist](../duelist_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry allows the Caster to instantly recover a single expended Skill. A target can benefit from this effect no more than once per Reset regardless of its source.<br/>
