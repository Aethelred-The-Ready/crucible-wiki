# Awakening Shout
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry instantly removes all [Compulsions](/docs/glossary/compulsion) effects from the target. The following effects are Compulsions; [Calm](/docs/glossary/compulsion#calm), [Charm](/docs/glossary/compulsion#charm), [Dominate](/docs/glossary/compulsion#dominate), [Fear](/docs/glossary/compulsion#fear), [Shun](/docs/glossary/compulsion#shun), [Silence](/docs/glossary/compulsion#silence), [Sleep](/docs/glossary/compulsion#sleep). This Artistry does not affect [Enthral](/docs/glossary/enthral).<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Dispel](/docs/glossary/dispel) [Compulsions](/docs/glossary/compulsion)"<br/>
