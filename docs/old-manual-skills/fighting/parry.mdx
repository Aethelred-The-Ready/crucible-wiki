# Parry
import Skill from '../skill.tsx'

<b>Requirements:</b> Weapon Training 2 per Rank\
Once per Reset, for every time this Skill is bought, the Character may negate any attack delivered, by weapon or packet, as [&lt;Effect>-Strike or Physical](../../glossary/delivery-types) by which they are struck. In order to use this Skill the Character must have a Weapon or Shield in hand. This ability cannot be used if the Character is under an effect which prevents the Character from using Weapons or if the Item is Fumbled. Effects delivered as [Arcane-Strike](../../glossary/delivery-types#arcane) cannot be avoided by this, or any other, ability. The call for this ability is “Parry”.\
If the Character has the [Bodyguard](../background/bodyguard) Skill they can use this ability to negate an applicable attack which strikes the target of their Bodyguard Skill when they are within their Weapon's reach.
