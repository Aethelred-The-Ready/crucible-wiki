# Overcome
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry instantly removes all harmful effects from the Caster which would be removed by the Caster's death. The Caster's player makes the determination as to which effects are harmful.<br/>
