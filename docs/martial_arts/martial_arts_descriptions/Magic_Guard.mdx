# Magic Guard
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Artistry grants the Caster a [Shield](/docs/glossary/shield) against the next effect delivered as [Magic(-Strike)](/docs/glossary/delivery-types#magic) by which they are struck.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Magic](/docs/glossary/delivery-types#magic) [Shield](/docs/glossary/shield)"<br/>
