# Sense Poison
<b>Requirements:</b> None<br/>
<b>Benefit:</b> A Character with this Skill is able to spend a sixty(60)-count to Detect the presence of [Poison](/docs/glossary/delivery-types#poison) or Alchemy on, or within, any item they are touching.

If the Character has both this Skill and either the Skill Apothecary or Chemist they may Identify what effect is present.<br/>
