# Iron Hide
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Artistry grants the target a [Ward](/docs/glossary/Ward) allowing them to negate a single effect delivered as [Physical](/docs/glossary/delivery-types#physical)(- Strike) by which they are struck. The target chooses when to activate this ability.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) Physical [Ward](/docs/glossary/Ward)"<br/>
