# Resist Magic [Heritage, Magical]
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset the Character may negate a single effect delivered as Magic(-Strike) by which they are struck. The call for this ability is "[Resist](/docs/glossary/resist)". If the Character has the Skill [Absorb](/docs/glossary/absorb) Magic, they also benefit from a "[Magic](/docs/glossary/delivery-types#magic) [Refit](/docs/glossary/refit) [Arcane Armour](/docs/equipment/non-physical-armour)". The call for this ability, in this latter case, is "Resist. Magic Refit Arcane Armour".<br/>

Category: [Magic](.)
