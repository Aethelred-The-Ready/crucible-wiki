---
title: "Imbue Skill: <Skill Name>"
---

This effect grants the
target the Skill or ability specified by the effect. For
example, there are a number of spells which grant
the target armour. Effects which grant the same Skill
or ability do not stack. For example a Character who
is granted “Natural Armour 5” and “Natural Armour
10” has ten(10) points of Natural Armour, not
fifteen(15). If the Skill granted by the effect is not
passive, the Character must state Activate prior to the
Delivery Verbal or Activation Call. Unless stated
otherwise, this ability ends at the end of the Day.
