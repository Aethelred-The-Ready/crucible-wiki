# Natural Fortification
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may grant themselves a "[Physical](/docs/glossary/delivery-types#physical) [Fortify](/docs/glossary/fortify) 5" effect. Once per Reset, the Character may Rest in order to restore all uses of this Skill.<br/>
