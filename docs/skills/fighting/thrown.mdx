# Thrown
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to wield a [Avoidance Armour](/docs/equipment/weapons)s in combat. Thrown Weapons may never possess a core and must be sculpted only using foam. Additionally, never aim for illegal areas including the head, groin and face. For information of the requirements for the [Physical Representations](/docs/equipment) for this, and other Weapons, see Chapter 5: Equipment.<br/>
