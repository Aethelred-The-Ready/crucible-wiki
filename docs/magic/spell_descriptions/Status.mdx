# Status
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Self and Touch<br/>
<b>Duration:</b> Concentration<br/>
<b>Effect:</b> This Spell allows the Caster to use the [Diagnose](/docs/skills/background-skills/diagnose) Skill on the target. This effect ends as soon as the Caster goes ten(10) seconds without asking a new question or performs any action, or suffers any effect, which would Disrupt Spell Casting.<br/>
<b>Incantation:</b> "I call upon the Dawn to reveal your Status."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Imbue Skill](/docs/glossary/imbue-skill): [Diagnose](/docs/skills/background-skills/diagnose)"<br/>
