# Natural Dodge
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to, once per Reset, negate a single effect, delivered by Weapon or Packet, by which they are struck, as per the Skill Dodge. This Skill does not count as a prerequisite for any other Skill. The Call for this ability is "Dodge".<br/>
