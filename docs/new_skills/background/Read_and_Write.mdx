# Read and Write
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to read and write in all languages they know. Without this Skill the Character is unable to read or recognize even the simplest of symbols.

Please note that this does not mean a Character without this Skill is stupid or unable to perform maths, merely that they are unable to understand any form of written media.

Read and Write is not Considered a Skill for any effect or action which limits the use of Skills. Meaning it is possible to read while Meditating, Resting or even while casting [Ritual Magic](/docs/rituals).<br/>
