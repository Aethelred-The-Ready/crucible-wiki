# Disintegoo
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Alchemy [Destroy](/docs/glossary/destroy)s the target item. A Destroyed item cannot be [Repair](/docs/glossary/repair)ed. Certain creatures, such as Constructs, may be damaged by this Alchemy. If the target has multiple items in their possession which match the description of the item designated by the Caster it is the target who chooses which of their items are affected. The target cannot choose an item which is [Indestructible](/docs/glossary/indestructible) unless it is the only item they have which matches that description.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Destroy](/docs/glossary/destroy) &lt;Item&gt;"<br/>
