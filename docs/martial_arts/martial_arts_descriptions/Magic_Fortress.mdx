# Magic Fortress
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Artistry grants the Caster a [Ward](/docs/glossary/Ward) allowing them to negate a single effect delivered as [Magic-Strike](/docs/glossary/delivery-types#magic) by which they are struck. The Caster chooses when to activate this ability.<br/>
