# Imbue Alchemy
<b>Cost:</b> P5 C2 E2 + See Text<br/>
<b>Type:</b> Alchemy<br/>
<b>School:</b> None<br/>
<b>Target:</b> Any Item or Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> As part of casting this Ritual the [Caster](/docs/rituals/ritual_glossary#Caster) chooses one(1) Alchemy they can cast from memory. This Ritual requires an amount of additional Power equal to one-third (1/3) the level of the Alchemy to be stored, rounded up. This Ritual imbues the ability to cast the chosen Alchemy into the target. The Caster cannot use their own Skills to modify the Alchemy in any way. The Character who is attuned to the item, or is the target of this effect, may cast the imbued Alchemy once per [Reset](/docs/glossary/reset). The call to use an Alchemy which is imbued is "Activate  &lt;Delivery Verbal&gt;". A Character cannot use their own Skills to modify an Alchemy which is cast using this effect.<br/>

This Ritual can be cast on a target more than once
