# Contingent Slime
<b>Requirements:</b> Level 9 Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may cast an Alchemy and have it triggered upon one of the following conditions; Dead, Dying, [Berserk](/docs/glossary/berserk)ed, [Binding](/docs/glossary/binding), Compelled, [Curse](/docs/glossary/curse)d, [Enthral](/docs/glossary/enthral)ed, [Imprison](/docs/glossary/imprison)ed, Poisoned, [Sleep](/docs/glossary/compulsion#sleep)ing, or Unconscious, chosen at the time of casting. If the Character dies before this effect is used it is lost. The call to first activate this ability is "I Invoke a &lt;Delivery Verbal&gt; Slime, Contingent upon my &lt;Trigger State&gt;." A Character may have only one [Contingency](/docs/glossary/delivery-types#contingency) effect, from this Skill, at a time. The call when this ability is triggered is "Contingency: &lt;Delivery Verbal&gt;".<br/>
