# Elemental Ward
<b>School:</b> [Conjuration](../conjuration_list), [Protection](../protection_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Spell grants the target the ability to negate a single effect delivered as [Elemental(-Strike)](/docs/glossary/delivery-types#elemental) by which the target is struck. The target's Player chooses when this ability activates.<br/>
<b>Incantation:</b> "I grant you the protection of an Elemental Ward."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Elemental](/docs/glossary/delivery-types#elemental) [Ward](/docs/glossary/Ward)"<br/>
