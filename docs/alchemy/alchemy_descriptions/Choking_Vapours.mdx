# Choking Vapours
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Alchemy prevents the target from speaking or casting Spells with an Incantation. Additionally, the target cannot intentionally create any sound such as clapping or using a noise making tool.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Silence](/docs/glossary/compulsion#silence)"<br/>
