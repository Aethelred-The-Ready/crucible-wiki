# Smithing, Grand Master
<b>Requirements:</b> [Master Smithing](/docs/skills/crafting/smithing_master.mdx), [Smithing](/docs/skills/crafting/smithing.mdx) 20<br/>
<b>Benefit:</b> This Skill grants the Character the ability to cast Ritual Smithing. Upon gaining this Skill the Character can act as the Primary Caster, or as a Secondary Caster, for any Ritual Smithing. Additionally, the Character gains the ability to cast Invocations. See Chapter 8: Rituals for more information on casting Ritual Smithing and Invocations.

The Character can also use this Skill to [Identify](/docs/invocations/invocation_descriptions/identify) any number of Ritual Components on a sixty(60)- count.<br/>
