# Fieldwork
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character does not require a Crafting Table to use the special abilities from Create [Diagnose](/docs/skills/crafting-skills/potion), Create [Diagnose](/docs/skills/crafting-skills/scroll), and Smithing. The Character still requires a Crafting Table in order to use the abilities granted from other Skills such as Augment Potion, or Create Wand.<br/>
