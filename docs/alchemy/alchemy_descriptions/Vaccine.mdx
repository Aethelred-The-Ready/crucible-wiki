# Vaccine
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Alchemy grants the target a [Shield](/docs/glossary/shield) against the next effect delivered as [Poison-Strike](/docs/glossary/delivery-types#poison) by which they are struck.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) Poison [Shield](/docs/glossary/shield)"<br/>
