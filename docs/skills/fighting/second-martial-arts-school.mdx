# Second Martial Arts School
import Skill from '../skill.tsx'

<b>Requirements:</b> [First Martial Arts School](./first-martial-arts-school)\
This Skill grants the Character access to their second [Martial Arts School](../../martial-arts/schools). The Character is able to expend their [Martial Arts Slots](./martial-arts-slot) to use the Martial Arts which belong to this school, and any other School the Character knows.
