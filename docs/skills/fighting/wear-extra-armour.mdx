# Wear Extra Armour
import Skill from '../skill.tsx'

<b>Requirements:</b> None\
The Character increases the maximum
number of [Wear Points of Armour](../../glossary/armour) the Character can
benefit from by five(5) for each time this Skill is
bought. A Character can benefit from, at most, a total
of fifty(50) points of Armour.
