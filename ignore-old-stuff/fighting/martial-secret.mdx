# Martial Secret
import Skill from '../skill.tsx'

<b>Requirements:</b> Martial Kata\
This Skill grants the Character to perform, without the need of a Martial Treatise, a single [Martial Kata](../../kata) of their choice. This Skill cannot be used to learn any Martial Kata which is marked as Limited in its description.
