# Quickness
<b>Requirements:</b> None<br/>
<b>Benefit:</b> A Character with this Skill gains ten(10) points of [Avoidance Armour](/docs/equipment/non-physical-armour). A Character is still limited by their Wear Total which limits the maximum number of Armour Points of any type from which the Character may benefit.

Avoidance Armour is represented by the Character wearing a number of feathers equal to the total Armour Point value of the armour divided by ten(10). These feathers must be attached to a single accessory which is worn by, and visible upon, the Character.<br/>
