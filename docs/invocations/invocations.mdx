# Invocations

Invocations are powerful abilities that those who
have learned to perform Rituals are able to perform.
In order to perform an Invocation the Character must
have a Focus. A Focus is a book, scroll, or similar
object measuring at least 10cm by 15cm which the
Character references as part of performing the
Invocation. A Character must attune to their focus by
performing a special five(5) minute ceremony to do
so. Once attuned the Character remains attuned to
the Focus until the current Event ends, or they attune
to another Focus.

 A Character is able to perform an Invocation of any
Type for which they have the appropriate Ritual skill.
A Character with Ritual Magic can perform any Magic
Invocation. All Invocations require a special sixty(60)-
second count to activate during which time the
Character references their Focus. An interrupted
count does not expend a use. A Character is only
able to perform a limited number of Invocations each
Reset. Generally speaking, any Skill which causes a
Character to count as an additional Caster for a
Ritual effect also increases the number of Invocations
a Character can cast each Reset.

 No Character may have more than one copy of any
Invocation at a time, even if they cast it using a
different method such as Smithing and Alchemy. Any
casting of an Invocation, the Character is already
under the effect of, removes and replaces the old one
with the new one.

 The effects of any active Invocation ends if the
Character enters their Death Count, they lose
possession of their Focus or they are subjected to an
appropriate Destroy &lt;Alchemy/Magic/Smithing&gt;
effect.

 A Character may have no more than five(5)
Invocations active at any time. Invocations whose
effects are instant, such as Identify, do not count
against this maximum. Should the Character perform
a sixth Invocation they choose which of their active
Invocations is replaced.

## Augmentation Tomes
Augmentation Tomes are special items which can
be used by any Character who has the ability to
perform the Invocation of their type. A Character with
the ability to perform Magic Invocations can use any
Augmentation Tome whose Type is specified as
Magic, Greater Magic, or Superior Magic.

 These Tomes may be found as treasure or created
with Limited Ritual Effects. All Augmentation Tomes
are Indestructible. A Character can attune to, and
benefit from, no more than one(1) Augmentation
Tome per Reset even if they can perform Invocations
of multiple types.
