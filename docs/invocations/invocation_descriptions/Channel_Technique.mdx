# Channel Technique
<b>Type:</b> Alchemy, Magic<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) grants the Caster three(3) Charges. The Caster may expend one(1) Charge when casting a Technique with a Range of Packet to instead deliver the Technique as an [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) with any weapon with which the Character is Proficient.<br/>
