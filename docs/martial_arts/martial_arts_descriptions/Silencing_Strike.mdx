# Silencing Strike
<b>School:</b> [Duelist](../duelist_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Artistry prevents the target from speaking or casting Spells with an Incantation. Additionally, the target cannot intentionally create any sound such as clapping or using a noise making tool.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical-Strike](/docs/glossary/delivery-types#physical) [Silence](/docs/glossary/compulsion#silence)"<br/>
