# Hush
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 3<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 10 Seconds<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Spell prevents the target from speaking or casting Spells with an Incantation. Additionally, the target cannot intentionally create any sound such as clapping or using a noise making tool.<br/>
<b>Incantation:</b> "I Compel you to be Hushed."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Lesser](/docs/glossary/delivery-types#lesser) [Magic](/docs/glossary/delivery-types#magic) [Silence](/docs/glossary/compulsion#silence)"<br/>
