# Funerary Rites
<b>Cost:</b> P1 S1<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Affliction](/docs/magic/affliction_list), [Restoration](/docs/magic/restoration_list)<br/>
<b>Target:</b> Any Permanently Dead Creature<br/>
<b>Duration:</b> Up to 5 Minutes<br/>
<b>Effect:</b> This Ritual allows the [Caster](/docs/rituals/ritual_glossary#Caster) to summon the spirit of a permanently dead creature to the [Circle](/docs/rituals/ritual_glossary#Circle). The maximum duration of this Ritual is five(5) minutes. The maximum number of years which can have elapsed since the target's death is ten(10) years. Each additional caster doubles the maximum number of years in this range.<br/>
