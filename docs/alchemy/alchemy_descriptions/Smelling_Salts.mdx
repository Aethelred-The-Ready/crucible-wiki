# Smelling Salts
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Alchemy instantly removes all [Compulsion](/docs/glossary/compulsion)s effects from the target. The following effects are Compulsions; [Calm](/docs/glossary/compulsion#calm), [Charm](/docs/glossary/compulsion#charm), [Dominate](/docs/glossary/compulsion#dominate), [Fear](/docs/glossary/compulsion#fear), [Shun](/docs/glossary/compulsion#shun), [Silence](/docs/glossary/compulsion#silence), [Sleep](/docs/glossary/compulsion#sleep). This Spell does not affect [Enthral](/docs/glossary/enthral).<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Dispel](/docs/glossary/dispel) [Compulsion](/docs/glossary/compulsion)"<br/>
