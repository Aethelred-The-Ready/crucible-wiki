# Control Elemental
<b>School:</b> [Conjuration](../conjuration_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This Spell places the target mindless [Elemental](/docs/glossary/delivery-types#elemental) under the Caster's complete control. The target will obey all the Caster's orders including self destructive ones. This Spell removed any previous casting of [Claws](/docs/glossary/control) Elemental from the target.<br/>
<b>Incantation:</b> "I Compel this Elemental to be Controlled."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Claws](/docs/glossary/control) [Elemental](/docs/glossary/delivery-types#elemental)"<br/>
