# Echo Slime
<b>Requirements:</b> Level 1 Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a copy of the last Alchemy they cast. This ability must be activated within ten(10) seconds of the initial Alchemy. The copy includes all the same options, including any and all Mutations and other abilities used on the first Alchemy. The call for this ability is "[Echo](/docs/glossary/echo): &lt;Delivery Verbal of copied Alchemy&gt;".<br/>
