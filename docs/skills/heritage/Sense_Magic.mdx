# Sense Magic
<b>Requirements:</b> None<br/>
<b>Benefit:</b> A Character with this Skill is able to spend a sixty(60)-count to Detect the presence of magic on any item they are touching.

If the Character has both this Skill and the Skill Magical Aptitude they may identify what School(s) of Magic are present on the item.<br/>
