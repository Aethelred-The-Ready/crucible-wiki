# Harden Magic
<b>Requirements:</b> Level 5 [Spell Slot](/docs/skills/magic/Spell_Slot.mdx)<br/>
<b>Benefit:</b> Once per [Reset](/docs/glossary/reset), for every time this Skill is bought, the Character may [Resist](/docs/glossary/resist) an effect which would [Remove](/docs/glossary/remove), or [Dispel](/docs/glossary/dispel), one or more [Magic](/docs/glossary/delivery-types#magic) effects including [Arcane Armour](/docs/equipment/non-physical-armour). This ability is usable even if the Character is inside of an [Imprison](/docs/glossary/imprison) allowing them to prevent their Imprison from being removed. It cannot be used against [Nullify](/docs/glossary/nullify) or [Abolishment](/docs/glossary/abolishment) effects.<br/>
