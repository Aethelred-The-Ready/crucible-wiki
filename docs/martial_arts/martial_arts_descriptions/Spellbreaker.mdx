# Spellbreaker
<b>School:</b> [Slayer](../slayer_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Artistry instantly removes all effects which were delivered as [Magic](/docs/glossary/delivery-types#magic)(-Strike) from the target.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical)-Strike [Dispel](/docs/glossary/dispel) [Magic](/docs/glossary/delivery-types#magic)"<br/>
