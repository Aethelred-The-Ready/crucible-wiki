# Heroic Stand
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Sustained<br/>
<b>Effect:</b> This Artistry grants the Caster [Physical](/docs/glossary/delivery-types#physical) [Resistance](/docs/glossary/resistance). This effect reduces all damaging effects delivered as [Physical-Strike](/docs/glossary/delivery-types#physical) by half as well as reducing the duration of all effects delivered as Physical(-Strike) to ten(10) seconds. This effect ends if the Character dies, enters a state where they are unable to use Skills, uses any other Artistry or Combat ends. Combat is considered to be over when the Character goes one(1) minute without attacking, or being attacked by, an enemy.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Imbue Skill](/docs/glossary/imbue-skill): Physical [Resistance](/docs/glossary/resistance)"<br/>
