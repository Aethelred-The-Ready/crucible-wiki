# Refit Any Armour
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell instantly restores all Armour Points, regardless of type, the target possesses, to its full value.<br/>
<b>Incantation:</b> "I alter this form to Refit Any Armour."<br/>
