# Vertigo
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 minutes<br/>
<b>Effect:</b> This Alchemy prevents the target from running or even standing up right. The target cannot use any Skills and, additionally, can neither walk, nor run, being restricted to crawling for movement.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Vertigo](/docs/glossary/vertigo)"<br/>
