# Oil of Slipperiness
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 10 Seconds<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Alchemy prevents the target from using a single weapon chosen by the Caster, or using any Skill requiring the use of the weapon for its duration. If the target is wielding more than one weapon which matches the description named by the Caster it us up to the target which weapon is affected.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Fumble](/docs/glossary/curse#fumble) &lt;Item&gt;"<br/>
