# Compulsion Shield
<b>School:</b> [Affliction](../affliction_list), [Protection](../protection_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell negates the next [Compulsion](/docs/glossary/compulsion) effect by which the target is struck. The following effects are [Compulsions](/docs/glossary/compulsion); [Calm](/docs/glossary/compulsion#calm), [Charm](/docs/glossary/compulsion#charm), [Dominate](/docs/glossary/compulsion#dominate), [Fear](/docs/glossary/compulsion#fear), [Shun](/docs/glossary/compulsion#shun), [Silence](/docs/glossary/compulsion#silence), and [Sleep](/docs/glossary/compulsion#sleep). [Enthral](/docs/glossary/enthral) is not a Compulsion.<br/>
<b>Incantation:</b> "I grant you the protection of a Compulsion Shield."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Compulsion](/docs/glossary/compulsion) [Shield](/docs/glossary/shield)"<br/>
