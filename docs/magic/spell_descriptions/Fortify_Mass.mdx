# Fortify, Mass
<b>School:</b> [Protection](../protection_list), [Restoration](../restoration_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Self and Touch<br/>
<b>Duration:</b> Concentration<br/>
<b>Effect:</b> This Spell allows the Caster to deliver a [Contingency](/docs/glossary/delivery-types#touch) effect which grants five(5) [Fortification Points](/docs/glossary/fortify) to any target. The Caster may continue to deliver this Touch effect to any number of creatures but this effect ends if the Caster goes ten(10) seconds without affecting a new target. No target may benefit from this effect more than once from a single casting. This Spell also ends if the Caster casts another Spell or suffers any effect which would Disrupt Spell casting including taking damage or entering a state which would prevent them from casting Spells. The Caster cannot run while Concentrating.<br/>
<b>Incantation:</b> "I grant the Masses the protection of Fortification."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Fortify](/docs/glossary/fortify) 5" … "Magic Fortify 5"<br/>
