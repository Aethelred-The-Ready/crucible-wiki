# Sending
<b>Cost:</b> P1 C1 S1<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Conjuration](/docs/magic/conjuration_list), [Restoration](/docs/magic/restoration_list)<br/>
<b>Target:</b> Any Character<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Ritual allows the caster to send a message consisting of ten(10) words, plus one(1) additional word for per [Caster](/docs/rituals/ritual_glossary#Caster), to the target.<br/>
