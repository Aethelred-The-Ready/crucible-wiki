# Stabilise

This effect can only affect a Character
who is [Dying](./states-of-living#dying) and in the Bleed Out count. The
Character is healed to zero(0) Hit Points, is no longer
Dying but is still [Unconscious](./states-of-living#unconcious). After being
unconscious for one(1) minute, the Character
recovers, returning to Consciousness at one(1) Hit
Point.
