# Ambush
<b>School:</b> [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Spell grants the target the ability to use any one(1) Skill, which requires the target to be behind the target, regardless of their position.<br/>
<b>Incantation:</b> "I grant you the power of an Ambush."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Ambush](/docs/glossary/ambush) 1"<br/>
