# Break &lt;Item&gt;

This effect Breaks the target item. A
Broken item cannot be used until it is Repaired. Certain
creatures, such as Constructs, may be damaged by this
effect. If the target has multiple items in their possession
which match the description of the item designated by
the user it is the target chooses which of their items are
affected. The target cannot choose an item which is
Indestructible unless it is the only item in their
possession which matches the description.
