# Defy Death
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry instantly restores the [Dead](/docs/glossary/states-of-living) target to life. The creature is no longer dead and is healed to one(1) Hit Point. If this Spell is cast upon a creature that is not Dead it has no effect but may be recovered by the Caster by Meditating.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Life](/docs/glossary/life)"<br/>
