# Delivery Verbals & Ability Calls

Almost all effects in Crucible have a Delivery
Verbal or “Call” associated with them. Everything
from Spells, to Alchemy, to defensive skills like Resist
Poison have a requirement for the Player to say their
associated verbals. All Delivery Verbals must be
spoken in a clear voice loud enough for their target to
hear the effect. This does not mean screaming as
loud as possible, merely speaking them so others can
hear and recognize the effect the Character is using.
All abilities require their full Delivery Verbal to be said
prior to swinging any weapon, or throwing any
packet. While we all occasionally get excited or make
mistakes any Player who is consistently delivering the
attack before completing the Delivery Verbal may be
subject to disciplinary actions.


Delivery Verbals follow a few standard patterns, that should be easy enough to pick up. Some examples are given below
| Amount | [Delivery Type](./delivery-types) | Effect | Subtype |
|-|-|-|-|
| 5 | ||normal|
| 5 |  ||silver|
| 5 | normal | sleep |  |
| 5 | elemental |  | fire |
| 5 | physical |  | [body](./body) |
| 5 | magic | [healing](./healing) |  |
|  | magic | [remove](./remove) [poison](./deliver-types#poison) |  |
|  | poison | [cripple](./cripple) |  |


Amount specifies how much of whatever is happenning happens.

Delivery Type is used for defence and removal of effects.
- If unspecified, it is Physical, but a subtype (normal, silver, iron) must be specified

Effect is what effect is delivered, alongside the damage if appropriate.
- Healing heals based on amount
- Any other "Carrier" effect only triggers if the damage is dealt to your hit point pool
- When unspecified the only effect is damage

Subtype interacts with defences and weaknesses. There are 16 subtypes that can be called
- Any of the 12 elements
- Silver, Iron, and Normal
- Body
