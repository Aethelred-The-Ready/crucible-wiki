# Penance
<b>Requirements:</b> Level 7 Martial Art Slot  or [Weapon Training](/docs/new_skills/fighting/Weapon_Training.mdx) 5<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, as long as the Character has at least one(1) Armour Point of [Physical Armour](/docs/equipment/armour) available they may expend all remaining Physical Armour Points to grant themselves a "Physical [Dispel](/docs/glossary/dispel) Curse" effect. The call for this ability is "Absorb. Physical Dispel Curse". This ability may be used event if the Character is under an effect which prevents them from using Skills such as [Drain](/docs/glossary/curse#drain) or Paralysis.<br/>
