# Callisthenics
<b>School:</b> [Duelist](/docs/martial_arts/martial_arts#school)<br/>
<b>Effect:</b> For every Rank the character has in the Skill Martial Kata, they may designate one(1) Character as a target of this Kata. Every target, other than the Caster, gains a single use of the [Dodge Skill](/docs/skills/expertise/dodge) allowing them to, Once per [Reset](/docs/glossary/reset), avoid a single effect delivered by weapon or packet. No target can benefit from this Kata more than Once per Reset.<br/>
