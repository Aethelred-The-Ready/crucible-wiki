# Ranger Bond, Hunter
<b>Cost:</b> P2 D1 S2<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Protection](/docs/magic/protection_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Leather Armour<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual requires the target Suit of Leather Armour to include the front of the torso and at least four other areas. This effect grants the wearer of the Armour the ability to grant themselves a "[Physical](/docs/glossary/delivery-types#physical) [Ambush](/docs/glossary/ambush) 5" or "Physical [Vorpal](/docs/glossary/vorpal) 5" effect. This ability is usable at will, but the Character must Rest in between uses. Multiple casting of this Ritual Effect on a single target increases the number of times its effects may be used between Rests. <br/>
