# Ready Armour
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) increases the Armour Points, granted by any [Physical Armour](/docs/equipment/armour), worn by the Character by ten(10). This effect stacks with all other effects which Reinforce Physical Armour.<br/>
