---
title: "Refit <Type> Armour"
---

This effect instantly restores
the target armour type worn by the target of this effect
to its full [Armour Point](/docs/combat/armour-points) total. This has no effect on
armour that has been [Broken](/docs/glossary/break) or [Destroyed](/docs/glossary/destroy).

### Refit All \{#all}
A "Refit All Armour" effect refits all armour of all types worn by the target
