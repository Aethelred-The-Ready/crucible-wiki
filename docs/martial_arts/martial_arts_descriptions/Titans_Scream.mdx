# Titan's Scream
<b>School:</b> [Slayer](../slayer_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry allows the Caster to throw any number of packets causing ten(10) points of [Physical](/docs/glossary/delivery-types#physical) Force damage to any creature struck by one or more packets.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "10 [Physical](/docs/glossary/delivery-types#physical) Force"<br/>
