# Curse Shield
<b>School:</b> [Affliction](../affliction_list), [Protection](../protection_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell negates the next [Curse](/docs/glossary/curse) effect by which the target is struck. The following effects are [Curses](/docs/glossary/curse); [Cripple](/docs/glossary/curse#cripple), [Drain](/docs/glossary/curse#drain), [Fetter](/docs/glossary/curse#fetter), [Fumble](/docs/glossary/curse#fumble), [Frailty](/docs/glossary/curse#frailty), [Paralysis](/docs/glossary/curse#paralysis), and [Weakness](/docs/glossary/curse#weakness).<br/>
<b>Incantation:</b> "I grant you the protection of a Curse Shield."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Curse](/docs/glossary/curse) [Shield](/docs/glossary/shield)"<br/>
