# Counter
<b>Requirements:</b> [Parry](/docs/skills/fighting/Parry.mdx) 2 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may negate and cause any attack, delivered by Weapon or Packet, causing Weapon Damage or effect delivered as [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) or [Physical](/docs/glossary/delivery-types#physical) by which they are struck causing it to rebound against its source. This ability is also usable against normal Weapon Damage. In order to use this Skill the Character must have a Weapon or [Shield](/docs/glossary/shield) in hand. This ability cannot be used if the Character is under an effect which prevents the Character from using Weapons or if the Item is Fumbled. Effects delivered as [Arcane-Strike](/docs/glossary/delivery-types#arcane) cannot be avoided by this, or any other, ability. The call for this ability is "[Reflect](/docs/glossary/reflect)".<br/>
