# Spell Bond
<b>Cost:</b> P2 C1 E1 T1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> Any &lt;See Text&gt;<br/>
<b>Target:</b> Silver Quiver<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual effect allows the [Caster](/docs/rituals/ritual_glossary#Caster) to choose a single Spell, with a Range of Packet that they can cast, as the Bonded Spell for this Ritual Effect. The Quiver functions similarly to a Spell Store [Item](/docs/rituals/ritual_glossary#Item), in that it allows the holder to [Absorb](/docs/glossary/absorb) a single copy of the Bonded Spell which is [Contingency](/docs/glossary/delivery-types#touch) Cast on the Character holding the Quiver. The Character with the Quiver may use the Quiver to cast the Stored Spell, delivering it as &lt;Delivery Type&gt;-Strike using an Archery Packet. Spells which are the target of one or more [Spellshapes](/docs/magic/spellshapes) or Invocations cannot be Stored. The call for Absorbing Spells is "Absorb". The call for casting the stored Spells is "Activate: &lt;Incantation&gt; &lt;Delivery Verbal&gt;-Strike".

 Multiple casting of this Ritual may either use the same Spell, or a different Spell. Each casting of this Ritual consumes one of the item's [Ritual Effect Slots](/docs/rituals/ritual_glossary#Ritual-Effect-Slots).<br/>

This Ritual can be cast on a target more than once
