# Knockout Strike
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 10 Seconds<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Artistry allows the Caster to deliver a [Lesser](/docs/glossary/delivery-types#lesser) [Physical](/docs/glossary/delivery-types#physical)-Strike [Sleep](/docs/glossary/compulsion#sleep) effect preventing them from moving or using any Skills. This Artistry lasts ten(10) seconds.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Lesser](/docs/glossary/delivery-types#lesser) [Physical](/docs/glossary/delivery-types#physical) Strike [Sleep](/docs/glossary/compulsion#sleep)"<br/>
