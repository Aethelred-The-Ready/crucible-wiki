---
title: "Remove <Effect>"
---
This effect removes a single
effect which matches the type specified by this effect.
For example a “Remove Curse” would remove a
single [Curse](./curse) effect from the target while a “Remove
Poison” would remove a single effect which was
delivered as [Poison](./delivery-types#poison) from the target. If a target has
multiple effects which match the type specified it is up
to the target as to which is removed.
