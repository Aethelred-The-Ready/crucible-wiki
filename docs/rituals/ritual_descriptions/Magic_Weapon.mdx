# Magic Weapon
<b>Cost:</b> P2 D2<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> Any<br/>
<b>Target:</b> Any Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Whenever a Weapon with this Ritual effect is used to deliver a Killing Blow, the wielder may deliver the Killing Blow as [Magic](/docs/glossary/delivery-types#magic) allowing them to kill certain powerful creatures requiring magic weapons to kill.<br/>
