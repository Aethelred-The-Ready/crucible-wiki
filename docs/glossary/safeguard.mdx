# Safeguard

This Effect magically seals the target
Container preventing any creature from accessing the
affected Container. Creatures which were touching
the target Container at the time of casting may add or
remove items from inside the Safeguard. This Effect
cannot be Dispelled. Characters can never be stored
inside of a Safeguard. The Container targeted by this
ability must be marked with an “S”. If this Effect is
cast upon a container within a [Sanctuary](/docs/glossary/sanctuary), the Caster
may choose to cause the target container to become
unmovable. This Effect must be included in the
Marshal Notes for the Room.
