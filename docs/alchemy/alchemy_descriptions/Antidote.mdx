# Antidote
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Alchemy removes all effects which were delivered as [Poison(-Strike)](/docs/glossary/delivery-types#poison) which are currently affecting the target.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Dispel](/docs/glossary/dispel) Poison"<br/>
