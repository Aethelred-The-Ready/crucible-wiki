# Hungering Shadows
<b>Type:</b> Shadow<br/>
<b>Benefit:</b> This Intervention grants all Adventurers the ability to use the damage bonus from any Skill or ability requiring them to be behind their target, such as Stealth Training, to receive its benefits. It also grants the Characters the ability to use any Skill which requires them to be behind their target. While under this effect the Character's base Weapon Call does not consume charges of the [Ambush](/docs/glossary/ambush) ability. This effect ends at the end of Combat. The call for this ability is "[Sound of Voice](/docs/glossary/delivery-types#sound-of-voice): All Adventurers, [Arcane](/docs/glossary/delivery-types#arcane) [Imbue Skill](/docs/glossary/imbue-skill): Ambush &lt;Infinite&gt;"<br/>
