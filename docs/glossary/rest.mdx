# Rest

This refers to a special five(5) minute action
where a Character recuperates from combat. It can
only be performed in Town or at a designated Rest
area. Certain Skills and abilities can be recovered if
the Character Rests. If the Character has multiple
abilities which require a Rest they may recover all of
them with a single Rest. A Rest is interrupted if the
Character is struck by any effect, other than Touch
Casting, the Character uses any Skills, or enters a
state where they are unable to use Skills.
