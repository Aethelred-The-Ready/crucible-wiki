# Fortress of Self
<b>School:</b> [Protection](../protection_list)<br/>
<b>Level:</b> 0<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Cantrip grants the Caster five(5) [Fortification Points](/docs/glossary/fortify). As a Cantrip, this effect can be used once, afterwards the Character must Rest in order to regain its use.<br/>
<b>Incantation:</b> None<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Fortify](/docs/glossary/fortify) 5"<br/>
