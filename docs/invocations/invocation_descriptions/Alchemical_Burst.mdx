# Alchemical Burst
<b>Type:</b> Alchemy<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) grants the Character three(3) Charges. The Character may expend one(1) Charge to throw any number of packets, with one hand, to deliver any Alchemy with a Range of Packet.<br/>
