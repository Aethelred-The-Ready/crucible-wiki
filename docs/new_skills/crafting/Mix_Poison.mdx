# Mix Poison
<b>Requirements:</b> Level 1 Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may mix an Alchemy, with a Range other than Self, they deliver from Memory, into food or drink. This process requires a three(3)-count and requires the Character to role-play mixing the poison into the food and mark the poisoned food's container with the name of the Alchemy it contains. It is possible to add multiple Alchemical effects to a single target but requires the count to be repeated for each additional effect. All effects expire at the end of the current Reset period. The first Character who consumes any amount of the poisoned food is affected by all effects bypassing Automatic Defenses.<br/>
