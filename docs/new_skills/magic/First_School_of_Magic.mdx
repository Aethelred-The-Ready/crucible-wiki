# First School of Magic
<b>Requirements:</b> Level 1 [Spell Slot](/docs/new_skills/magic/Spell_Slot.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character access to their first School of [Magic](/docs/glossary/delivery-types#magic). The Character is able to expend their Spell Slots to use the Spells which belong to this school. See [Spellcasting](/docs/magic/spellcasting) for more information on the Schools of Magic.<br/>
