# Channel Poison
<b>Cost:</b> P4 C2 E2 S2 T1<br/>
<b>Type:</b> Alchemy<br/>
<b>School:</b> None<br/>
<b>Target:</b> Any Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> At the time of this Ritual's casting the [Caster](/docs/rituals/ritual_glossary#Caster) chooses a single Alchemy, they can cast, with a range of Packet. Whenever the wielder casts the chosen Alchemy they may use this Weapon to deliver the effect as [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike). The Delivery Type of the attack changes to match that of the Channelled Alchemy.<br/>
