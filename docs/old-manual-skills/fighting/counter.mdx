# Counter
import Skill from '../skill.tsx'

<b>Requirements:</b> Parry 2 per Rank\
Once per Reset, for every time this Skill is bought, the Character may negate and cause any attack, delivered by Weapon or Packet, causing Weapon Damage or effect delivered as [&lt;Effect&gt;-Strike or Physical](../../glossary/delivery-types) by which they are struck causing it to rebound against its source. This ability is also usable against normal Weapon Damage. In order to use this Skill the Character must have a Weapon or Shield in hand. This ability cannot be used if the Character is under an effect which prevents the Character from using Weapons or if the Item is [Fumbled](../../glossary/curse#fumble). Effects delivered as [Arcane-Strike](../../glossary/delivery-types#arcane) cannot be avoided by this, or any other, ability. The call for this ability is [“Reflect”](../../glossary/reflect).
