# Simple Weapon
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to wield all Simple Weapons in combat. A Simple Weapon can only be used to block and can never be used to attack but can be used to deliver a Killing Blow. For information of the requirements for the [Physical Representations](/docs/equipment) for this, and other Weapons, see Chapter 5: Equipment.<br/>
