# Cleaving Weapon
<b>Cost:</b> P3 D2 T2<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> None<br/>
<b>Target:</b> Any Axe<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to [Echo](/docs/glossary/echo) a single Martial Art which they have just Cast from memory. The Echoed Martial Art includes all the same options, modifications, including effects from Katas and Martial Traditions, which were applied to the original Martial Art. The decision to use this ability must be made within ten(10) seconds of the original being delivered. The call for this ability is "Echo &lt;Delivery Verbal&gt;".<br/>
