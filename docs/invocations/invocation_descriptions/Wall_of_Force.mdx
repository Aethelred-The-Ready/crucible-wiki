# Wall of Force
<b>Type:</b> Magic<br/>
<b>Duration:</b> Charged (3)<br/>
<b>Effect:</b> This Invocation grants the Caster three(3) Charges. The Caster may expend one(1) Charge of this ability in order to deliver a packet delivered "[Arcane](/docs/glossary/delivery-types#arcane) [Repel](/docs/glossary/repel)" effect. Alternatively, the Character may expend all three(3) Charges, the Caster may throw any number of packets when delivering this effect. Any target struck by one(1) or more Packets is affected by this effect. <br/>
