import Skill from '../skill.tsx'

<b>Requirements:</b> None\
The Character gains the ability to wield all
[Two-Handed Weapons](../../equipment/weapons) in combat. At the time this
Skill is bought, the Character may “sell back” any
Skills which are included in its benefit.
