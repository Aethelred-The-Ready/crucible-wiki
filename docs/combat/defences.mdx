# Defences

### Automatic (Dumb) Defences
These defences are triggered by the first effect, to
which they are applicable, which strikes the target. If
a Character has multiple defences which are
applicable to an effect by which they are struck the
Player chooses which is triggered. A Character with
an automatic defence cannot choose for it not to be
triggered unless the effect is delivered by Touch.

### Choice (Smart) Defences
The defences are triggered at the Character’s
discretion and can be used to negate any effect to
which it is applicable. If a Character has multiple
defences which are applicable to an effect, by which
they are struck, the Player chooses which, if any, is
triggered. A Character can also choose not to activate
any Choice Defences after being struck by an
applicable effect.

## Defence Types

### Absorb &lt;Effect&gt; \{#absorb}
This ability negates an effect, to
which it is applicable, and grants the character a
charge in some ability as described by the Effect.
Unless stated otherwise by the source of this ability,
this is considered a “Choice” defence allowing the
Character to choose when to activate this ability. The
call for this ability is “Absorbed”.

### Block
This ability negates a single attack causing
Weapon Damage. Unless stated otherwise by the
source of this ability, this is considered a “Choice”
defence allowing the Character to choose when to
activate this ability. The call for this ability is “Block”.

### Counter
In order to use this defence the Character
must be wielding a weapon, or shield, with which they
are proficient, and not be under any effect, such as
Fumble, Weakness, Drain, or Cripple, which would
keep them from wielding that weapon with that hand.
This ability can be used to negate any effect which
causes Weapon Damage, or is delivered as Physical,
or &lt;Delivery Type&gt;-Strike. This ability causes the
attack to not only be negated, but Reflected back
against the attacker. An effect which is Reflected
follows all the same rules as the original attack. Any
effect which is reflected twice is fully negated. Unless
stated otherwise by the source of this ability, this is
considered a “Choice” defence allowing the
Character to choose when to activate this ability. The
call for this ability is “Reflect”

### Dodge
This ability can be used to negate any effect
which is delivered by Weapon or Packet. Unless
stated otherwise by the source of this ability, this is
considered a “Choice” defence allowing the
Character to choose when to activate this ability.
Effects delivered as Arcane(-Strike) cannot be
avoided by this, or any other, ability. The call for this
ability is “Dodge”

### Evasion
This ability can be used to negate any
effect which would affect the target. Unless stated
otherwise by the source of this ability, this is
considered a “Choice” defence allowing the
Character to choose when to activate this ability.
Effects delivered as Arcane(-Strike) cannot be
avoided by this, or any other, ability. The call for this
ability is “Evasion”.

### Immune
This ability completely
negates the effect to which it is applicable. The call
for this ability is “No Effect”. Effects which are
delivered as Arcane(-Strike) bypass any Immunity the
Character may possess.

### Parry
In order to use this defence the Character
must be wielding a weapon, or shield, with which they
are proficient, and not be under any effect, such as
Fumble, Weakness, Drain, or Cripple, which would
keep them from wielding that weapon with that hand.
This ability can be used to negate any effect which
causes Weapon Damage, or is delivered, by weapon
or packet, as Physical, or &lt;Delivery Type&gt;-Strike.
Unless stated otherwise by the source of this ability,
this is considered a “Choice” defence allowing the
Character to choose when to activate this ability.
Effects delivered as Arcane(-Strike) cannot be
avoided by this, or any other, ability. The call for this
ability is “Parry”.

### Resist &lt;Effect&gt; \{#resist}
This ability negates an effect, to
which it is applicable. This ability cannot be used
against any effect which is delivered as Piercing.
Unless stated otherwise by the source of this ability,
this is considered a “Choice” defence allowing the
Character to choose when to activate this ability. The
call for this ability is “Resist”.

### Reflect &lt;Effect&gt; \{#reflect}
This ability negates an effect, to
which it is applicable, and causes it to rebound
against the attacker. An effect which is Reflected
follows all the same rules as the original attack. Any
effect which is reflected twice is fully negated. Unless
stated otherwise by the source of this ability, this is
considered a “Automatic” defence being activated
automatically against the first effect, to which it is
applicable, by which the Character is struck. The call
for this ability is “Reflect”.

### &lt;Effect&gt; Resistance \{#resistance}
This passive defence has two
effects. Any effect, to which it is applicable, which
causes damage has its damage reduced by half,
rounded down. Any effect, to which it is applicable,
with a duration other than instant, has its duration
reduced to ten(10) seconds. This ability cannot be
used against any effect which is delivered as
Piercing. The call for this ability is “Reduced”.

### &lt;Effect&gt; Shield \{#shield}
This ability negates the first effect,
to which it is applicable. This ability cannot be used
against any effect which is delivered as Piercing. This
is considered an “Automatic” defence being activated
automatically against the first effect, to which it is
applicable, by which the Character is struck. The call
for this ability is “&lt;Effect&gt; Shield”.

### &lt;Effect&gt; Ward \{#ward}
This ability negates a single effect,
to which it is applicable. Unless stated otherwise by
the source of this ability, this is considered a “Choice”
defence allowing the Character to choose when to
activate this ability. The call for this ability is “Ward”
