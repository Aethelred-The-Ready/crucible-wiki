# Resist Poison
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may negate a single effect delivered as Poison(-Strike) by which they are struck. The call for this ability is "Resist".<br/>
