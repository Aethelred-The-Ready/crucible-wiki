# Shadow Intervention
<b>Requirements:</b> 20 Character Levels per Rank.<br/>
<b>Benefit:</b> This Skill allows the Character to perform an incredible act of stealth prowess beyond the limits of what should be possible. A Character can have only one Intervention Skill for every twenty(20) Character Levels they possess. Each Intervention Skill allows the Character to perform one(1) Intervention per Event. These uses can never be recovered. For more information on Interventions, see page 193.<br/>
