# Create Flask
<b>Requirements:</b> [Create Potion](/docs/new_skills/crafting/Create_Potion.mdx) 10<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may expend a single Spell or Alchemy Slot to create a Flask containing a Technique, the Character can cast, with a Range of Touch or Packet, of the same level as the expended Technique Slot. The Technique must have a Range of Touch or Packet. A Flask has five(5) Charges upon creation. The Character may then expending one(1) Charge from the Flask in order to deliver the chosen Technique against a target by having the target spend a three(3)-count role-playing drinking from the Flask.

A Flask must be marked with the Technique it contains, as well as the number of charges it contains, and must be a container which appears to hold one-hundred(100) to one-thousand(1000) millilitres of liquid.

In order to use this Skill the Character must have access to a [Diagnose](/docs/skills/crafting-skills/potion) Laboratory. All Flasks expire at the end of the Event.<br/>
