# Invigorating Shout
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry removes, from the target, the [Drain](/docs/glossary/curse#drain) effect. Since a target cannot have multiple instances of the same effect, this removes all Drains from the target. When delivering this effect, the Character may throw any number of packets.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Piercing](/docs/glossary/delivery-types#piercing) [Physical](/docs/glossary/delivery-types#physical) [Remove](/docs/glossary/remove) [Drain](/docs/glossary/curse#drain)"<br/>
