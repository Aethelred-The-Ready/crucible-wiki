# Purge Poison
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Concentration<br/>
<b>Effect:</b> Once this Spell is cast the Caster may deliver, at will, by [Contingency](/docs/glossary/delivery-types#touch), a "[Magic](/docs/glossary/delivery-types#magic) [Remove](/docs/glossary/remove) [Poison](/docs/glossary/delivery-types#poison)" effect removing a single effect, delivered as [Poison-Strike](/docs/glossary/delivery-types#poison) from the target. This effect ends if the Caster goes ten(10) seconds without affecting a new target. This Spell also ends if the Caster casts another Spell or suffers any effect which would Disrupt Spell casting including taking damage or entering a state which would prevent them from casting Spells. The Caster cannot run while Concentrating.<br/>
<b>Incantation:</b> "I call upon the Dusk to Purge Poison."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Remove](/docs/glossary/remove) [Poison](/docs/glossary/delivery-types#poison)" … "Magic Remove Poison"<br/>
