# Last Stand
<b>School:</b> [Guardian](/docs/martial_arts/martial_arts#school)<br/>
<b>Effect:</b> This Kata grants the Character one(1) Charge of this ability. The Character can expend one(1) Charge to activate this ability. Upon activating this ability the Character immediately enters a special state of [Immunity](/docs/combat/defences#immune). Upon entering this state the Character begins a five(5) minute countdown. During this count, the Character is [Immune](/docs/combat/defences#immune) to all effects. This effect ends as soon as one of the following occurs; the five(5) minute countdown ends, Character takes ten(10) steps, or the Character voluntarily ends this effect. Once this effect ends the Character is [Dead](/docs/combat/states-of-living) and the amount of time left in their [Death](/docs/glossary/death) Count is equal to the amount of time left on the five(5) minute countdown which began when this ability was first activated. If there is any time left in their Death Count, because they ended this ability before the countdown reaches zero(0), they may receive a [Life](/docs/glossary/life) Spell and any effects which trigger upon Death are triggered. If the countdown reaches zero(0) while the Character was still under this effect they immediately Dissipate as though their Death Count reached zero(0).

 This effect can be ended early due to the Character entering a state where they are unable to use Skills or Abilities, or forced to move, as a result of an effect delivered as [Arcane(-Strike)](/docs/glossary/delivery-types#arcane). In these states the effect ends as if the Character ended it voluntarily.<br/>
