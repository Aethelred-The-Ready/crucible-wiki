# Paralysing Strike[Curse]
<b>School:</b> [Duelist](../duelist_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Artistry completely immobilises the target preventing them from speaking, moving or using any Skills while in effect. This effect does not prevent the target from being moved.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical-Strike](/docs/glossary/delivery-types#physical) [Paralysis](/docs/glossary/curse#paralysis)"<br/>
