# Spell Splinter
<b>Cost:</b> P3 C2 S1 T1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Iron Quiver<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target Quiver with the following ability. Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to deliver an attack causing a "[Physical-Strike](/docs/glossary/delivery-types#physical) [Remove](/docs/glossary/remove) [Magic](/docs/glossary/delivery-types#magic)" effect. The Character must deliver this attack using Archery Packets but may throw, at once, any number of Packets.<br/>

This Ritual can be cast on a target more than once
