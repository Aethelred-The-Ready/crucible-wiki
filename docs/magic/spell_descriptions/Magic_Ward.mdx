# Magic Ward
<b>School:</b> [Protection](../protection_list), [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Charged<br/>
<b>Effect:</b> This Spell grants the target a [Ward](/docs/glossary/Ward) allowing them to negate a single effect delivered as [Magic](/docs/glossary/delivery-types#magic)(- Strike) by which they are struck. The target chooses when to activate this ability.<br/>
<b>Incantation:</b> "I grant you the protection of a Magic Ward."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) Magic [Ward](/docs/glossary/Ward)"<br/>
