# Preparation
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Artistry grants the Caster five(5) [Fortification Points](/docs/glossary/fortify).These Fortification Points are always the first lost due to damage. Multiple effects which grant Fortification Points do not stack.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Fortify](/docs/glossary/fortify) 5"<br/>
