# Remove Poison
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 3<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell removes, from the target, a single effect which was delivered as [Poison(-Strike)](/docs/glossary/delivery-types#poison). If the target is under multiple Poison effects, the target chooses which is removed.<br/>
<b>Incantation:</b> "I call upon the Dusk to Remove Poison."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Remove](/docs/glossary/remove) [Poison](/docs/glossary/delivery-types#poison)"<br/>
