# Duplicate Scroll
<b>Cost:</b> P2 C1 E1 T1 + See Text<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> All (See Text)<br/>
<b>Target:</b> Any Ritual Scroll<br/>
<b>Duration:</b> One(1) Year<br/>
<b>Effect:</b> This Ritual effect allows the Caster to create a duplicate of the target Ritual [Diagnose](/docs/skills/crafting-skills/scroll). As an additional cost to cast this Ritual the Caster must include additional components equal to the full Component cost of the Ritual effect being copied. Skills and effects which reduce the number of components needed to cast a Ritual cannot reduce the number of Components needed for this additional cost. When performed as a [Ritual Magic](/docs/rituals) effect this Ritual must target a Ritual Magic Scroll and creates a Ritual Magic Scroll. When cast as a Ritual Alchemy effect it targets and creates a Ritual Alchemy Formula. Ritual Smithing targets and creates a Ritual Smithing Schematic.<br/>
