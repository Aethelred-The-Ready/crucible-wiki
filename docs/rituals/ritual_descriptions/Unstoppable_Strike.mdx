# Unstoppable Strike
<b>Cost:</b> P4 D4 S2<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Two-Handed Melee Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to deliver a [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) as [Piercing](/docs/glossary/delivery-types#piercing). This ability can be used on Spells, Martial Arts, Alchemy and regular Skills.<br/>

This Ritual can be cast on a target more than once
