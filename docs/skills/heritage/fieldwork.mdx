# Fieldwork
<b>Requirements:</b> None

<b>Benefit:</b> The Character does not require a Crafting Table to use the special abilities from Create [Potion](/docs/skills/crafting/create_potion), Create [Scroll](/docs/skills/crafting/create_scroll), and Smithing. The Character still requires a Crafting Table in order to use the abilities granted from other Skills such as Augment Potion, or Create Wand.
