# Distracting Fumes
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 10 Seconds<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Alchemy prevents the target from willingly approaching the Caster or attacking the Caster. This effect ends if the Caster attacks the target.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Lesser](/docs/glossary/delivery-types#lesser) [Poison](/docs/glossary/delivery-types#poison) [Shun](/docs/glossary/compulsion#shun)"<br/>
