# Adhesive Splash
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Binding](/docs/glossary/binding) Alchemy allows the Character to throw any number of packets. Any creature struck by one or more packets is affected by a [Physical](/docs/glossary/delivery-types#physical) [Pin](/docs/glossary/binding#pin) effect preventing any target from moving, or lifting, their right foot though they may still pivot upon it.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Pin](/docs/glossary/binding#pin)"<br/>
