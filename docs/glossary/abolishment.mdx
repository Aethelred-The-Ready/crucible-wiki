# Abolishment

This effects removes all beneficial
effects from the target. This includes all Techniques with
a duration of Concentration, Charged or Sustained. It
also includes all Fortification Points, Shields, Wards,
Absorbs, Imbued Skills, Invocations as well as the
effects; Aegis, Ambush, Mirage, Vorpal, and &lt;Type&gt;
Aura.
