# Armour Bond
<b>School:</b> [Guardian](/docs/martial_arts/guardian_list)<br/>
<b>Effect:</b> This Kata increases the Character's Wear Point total by ten(10) to a maximum of fifty(50).

 Additionally, the value of any [Physical Armour](/docs/equipment/armour) the Character has is increased by ten(10). This effect stacks with all other effects which Reinforce Physical Armour.<br/>
