---
title: "<Effect> Immunity"
---

This effect grants [Immunity](/docs/combat/defences#immune) to
the specified effect. If the effect is a Deliver Type, the
target is Immune to all effects delivered as that
Delivery Type. If the effect is a specific effect such as
Fumble, the target is Immune to all Fumble effects
regardless of Delivery Type. The one exception to this
is if the effect is delivered as [Arcane(-Strike)](/docs/glossary/delivery-types#arcane). In this
case the target’s Immunity does not apply
