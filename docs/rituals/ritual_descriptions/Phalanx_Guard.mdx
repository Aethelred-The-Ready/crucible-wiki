# Phalanx Guard
<b>Cost:</b> P3 C2 T2 + See Text<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Protection](/docs/magic/protection_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Shield<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target [Shield](/docs/combat/defences#shield) with the ability to, once per [Reset](/docs/glossary/reset), negate a single effect Delivered as [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) which strikes the Wielder. The call for this effect is "Activate Parry".

 This Ritual requires a number of additional Power Components based on the size of the Shield. A Gauntlet or Buckler requires one(1) additional Power, a Small Shield requires two(2) additional Power while a large Shield requires three(3) additional Power. If this Ritual is performed as a Smithing Ritual the Smith may substitute a Special Material Ingot; Adamantine, [Iron](/docs/equipment/special-materials) or [Silver](/docs/equipment/special-materials), in place of the additional Power. For example if constructing a Small Shield the Smith could expend an Adamantine and Silver ingot in order to pay the addition two(2) Power needed to perform this Ritual on the target. <br/>

This Ritual can be cast on a target more than once
