# Shadow Knife
<b>School:</b> [Duelist](/docs/martial_arts/martial_arts#school), [Slayer](/docs/martial_arts/martial_arts#school)<br/>
<b>Effect:</b> This Kata grants the Character five(5) Charge of this ability. The Character can expend one(1) Charge to throw a packet in place of a [Avoidance Armour](/docs/equipment/weapons). This ability can be used to deliver any Martial Art with a range of Strike including those which can only be delivered by a Thrown Weapon. The Shadow Knife can also be used to deliver a Weapon Attack benefiting from any Weapon Training and Stealth Training the Character possesses.

 Additionally, the Character is considered to be behind their target for any other ability which requires them to be behind their target. The Weapon Type of the attack, if applicable, is changed to Shadow.

 Finally, as the packet attack is considered to be a Thrown Weapon, abilities such as Shadow Shot or Split Shot, which allow the Character to throw additional packets are applicable to this ability as well.<br/>
