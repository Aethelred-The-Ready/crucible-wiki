# Harvester
<b>Requirements:</b> None<br/>
<b>Benefit:</b> At the start of each Event, the Character receives one of the following items for each Game Day of the Event; one(1) Adamantine Ingot, one(1) [Iron](/docs/equipment/special-materials) Ingot, one(1) [Silver](/docs/equipment/special-materials) Ingot, or a single strength one(1) Ritual Component. The Ritual Component Type is random though Event Staff may accommodate requests for a specific type at their discretion.<br/>
