# Defensive Roll
<b>Requirements:</b> [Avoidance Armour](/docs/new_skills/expertise/Avoidance_Armour.mdx) 5 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, as long as the Character has at least one(1) Armour Point of [Avoidance Armour](/docs/equipment/non-physical-armour) available, they may expend all remaining Avoidance Armour Points to allow them to "Dodge" a single effect delivered by Weapon or Packet. The call for this ability is "[Absorb](/docs/glossary/absorb). Dodge.". A Character must Rest in between uses of this Skill.<br/>
