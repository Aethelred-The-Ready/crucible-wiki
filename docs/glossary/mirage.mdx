---
title: "Mirage <#>"
---

This effect grants the target a number of [Dodges](/docs/combat/defences#dodge)
against the next # effect, delivered by Weapon or Packet,
by which it is struck. Unlike the [Dodge Skill](/docs/skills/expertise/dodge), the target
does not choose when this ability activates, it is
automatically triggered as soon as the target is struck by
an applicable effect, as an [Automatic (Dumb) Defence](/docs/combat/defences)
