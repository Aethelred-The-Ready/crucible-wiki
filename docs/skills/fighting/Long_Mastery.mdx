# Long Mastery
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to wield all Long Weapons in combat. At the time this Skill is bought, the Character may "sell back" any Skills which are included in its benefit. For information of the requirements for the [Physical Representations](/docs/equipment) for this, and other Weapons, see Chapter 5: Equipment.<br/>
