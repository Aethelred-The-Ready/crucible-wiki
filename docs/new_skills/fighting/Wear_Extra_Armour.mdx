# Wear Extra Armour
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character increases the maximum number of Wear Points of Armour the Character can benefit from by five(5) for each time this Skill is bought. A Character can benefit from, at most, a total of fifty(50) points of Armour. <br/>
