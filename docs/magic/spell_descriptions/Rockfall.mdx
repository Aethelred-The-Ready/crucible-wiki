# Rockfall
<b>School:</b> [Conjuration](../conjuration_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell allows the Caster to throw any number of packets. Any target struck by one or more packets takes twenty(20) points of [Physical](/docs/glossary/delivery-types#physical) Stone damage.<br/>
<b>Incantation:</b> "I Conjure a Rockfall."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "20 [Physical](/docs/glossary/delivery-types#physical) Stone"<br/>
