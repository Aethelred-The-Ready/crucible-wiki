# Disinfect
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Charged (1)<br/>
<b>Effect:</b> This Alchemy grants the target a [Ward](/docs/glossary/Ward) allowing them to negate a single effect delivered as [Poison(-Strike)](/docs/glossary/delivery-types#poison) by which they are struck. The target chooses when to activate this ability.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) Poison [Ward](/docs/glossary/Ward)"<br/>
