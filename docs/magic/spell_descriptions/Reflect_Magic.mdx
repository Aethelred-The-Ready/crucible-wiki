# Reflect Magic
<b>School:</b> [Protection](../protection_list), [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell causes the next effect, delivered as [Magic](/docs/glossary/delivery-types#magic)(-Strike), by which the target is struck, to rebound against its source. The call for this effect, when triggered, is "[Reflect](/docs/glossary/reflect)".<br/>
<b>Incantation:</b> "I grant you the Protection of a Reflect Magic."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Reflect](/docs/glossary/reflect) Magic"<br/>
