# Binding Agent
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Binding](/docs/glossary/binding) Alchemy forces the target's arms to their sides and keeps them there throughout its duration. The creature cannot use any Skill which requires the use of their arms such as using weapons or casting Spells.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Bind](/docs/glossary/binding#bind)"<br/>
