# Recover Materials
<b>Cost:</b> P1 C1 D1 E1 S1 T1<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Magical Effect or Item<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Ritual [Destroys](/docs/glossary/destroy) the magic upon the target effect refunding a prorated portion, rounded down, of the components used to create it. The amount refunded is based on the total number of components, divided by the duration, multiplied by the number of months left. For example, an item which required P12, C8, E10, S8, and T6 to create, with one year left of its two year duration would refund P6, C4, E5, S4, and T6. If the same item had only four months left it would refund P2, C1, E1, S1 and T1. The refunded components are issues in the form of a [Component](/docs/rituals/ritual_glossary#Component) Voucher with the same expiry date as the original item.<br/>
