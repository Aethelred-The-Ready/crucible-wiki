# Sunder Magic
<b>Cost:</b> P1 D1 T1<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Affliction](/docs/magic/affliction_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Magical Effect<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Ritual [Destroys](/docs/glossary/destroy) the magic upon the target. This Ritual cannot be cast on creatures or Items. This Ritual can only be cast within a [Magic](/docs/glossary/delivery-types#magic) [Circle](/docs/rituals/ritual_glossary#Circle) created by the Create Magic Circle Ritual.

 The caster must be able to touch the effect during the casting. In the case of targeting a [Sanctuary](/docs/glossary/sanctuary), the caster must be able to touch one of the doorways, or portal, into the targeted Sanctuary.<br/>
