# Recuperation
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry causes the Caster to begin Regenerating. Upon being affected by this Artistry the Caster may immediately spend a sixty(60)-count to benefit from this effect. At the end of this count the Caster is restored to maximum Hit Points. This effect ends, without effect, if the Caster is affected by any damaging effect, uses any Skill, or moves faster than a normal walking pace.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Regenerate](/docs/glossary/regenerate)"<br/>
