# Healing Nova
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell allows the Caster to throw any number of packets. Any creature struck by one or more packets takes twenty(20) points of [Magic](/docs/glossary/delivery-types#magic) [Healing](/docs/glossary/healing).<br/>
<b>Incantation:</b> "I call upon the Dawn to create a Healing Nova."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "20 [Magic](/docs/glossary/delivery-types#magic) [Healing](/docs/glossary/healing)"<br/>
