# Hallucinogen
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 10 Seconds<br/>
<b>Effect:</b> This Alchemy prevents the target from running or even standing up right. The target cannot use any Skills and, additionally, cannot move without crawling. This Alchemy lasts ten(10) seconds.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Lesser](/docs/glossary/delivery-types#lesser) [Poison](/docs/glossary/delivery-types#poison) [Vertigo](/docs/glossary/vertigo)"<br/>
