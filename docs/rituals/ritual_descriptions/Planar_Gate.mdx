# Planar Gate
<b>Cost:</b> P4 C3 E3 S3 T3 + Special<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Conjuration](/docs/magic/conjuration_list), [Protection](/docs/magic/protection_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Circle<br/>
<b>Duration:</b> See Text<br/>
<b>Effect:</b> This Ritual causes the target [Circle](/docs/rituals/ritual_glossary#Circle) to become a gate to the target plane. This gate remains open for one(1) hour per [Caster](/docs/rituals/ritual_glossary#Caster) but can be closed early by any Caster touching it. Any creature travelling through the gate gains Planar Attunement to the plane they travel to.<br/>
