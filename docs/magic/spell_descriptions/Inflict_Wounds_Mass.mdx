# Inflict Wounds, Mass
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell allows the Caster to throw any number of packets. Any target struck by one or more packets takes ten(10) points of [Magic](/docs/glossary/delivery-types#magic) [Body](/docs/glossary/body) damage.<br/>
<b>Incantation:</b> "I call upon the Dusk to Inflict Wounds upon the Masses."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "10 [Magic](/docs/glossary/delivery-types#magic) [Body](/docs/glossary/body)"<br/>
