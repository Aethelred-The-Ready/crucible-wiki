# Imprison
<b>School:</b> [Protection](../protection_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This Spell encases the target in a magical field preventing them from speaking, moving, being moved, or using any Skills. While inside the [Imprison](/docs/glossary/imprison), the target is immune to all effects. This effect can be removed by a [Dispel](/docs/glossary/dispel) [Magic](/docs/glossary/delivery-types#magic) effect. The Caster may also end the Imprison effect by simply touching the target and stating "Imprison down". If the Caster is also the target they may expend one use of the Skill Harden Magic to negate a single Dispel Magic effect from removing the Imprison.

 The Caster can also use the Imprison to deliver a Killing Blow, which counts as Magic, upon the target. To do so the Caster must touch the target and state "Killing Blow 1, Killing Blow 2, Killing Blow 3, Magic"<br/>
<b>Incantation:</b> "I Conjure a Force to Imprison you."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Imprison](/docs/glossary/imprison)"<br/>
