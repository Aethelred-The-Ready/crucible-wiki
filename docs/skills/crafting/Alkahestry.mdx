# Alkahestry
<b>Requirements:</b> Level 9 Alchemy Slot<br/>
<b>Benefit:</b> This Skill grants the Character the ability to cast Ritual Alchemy. Upon gaining this Skill the Character can act as the Primary Caster, or as a Secondary Caster, for any Ritual Alchemy. Additionally, the Character gains the ability to cast Invocations, powerful Alchemical effects tied to their ability to perform Alkahestries. See Chapter 8: Rituals for more information on casting Ritual Alchemy and for the rules on casting Invocations.<br/>
