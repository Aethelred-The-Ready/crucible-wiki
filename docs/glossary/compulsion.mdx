# Compulsion

Compulsion effects are those
which affect the target's mind and can be [defended
against](./defences), or [Removed](./remove), by abilities which are applicable
against Compulsion effects or the [Delivery Type](./delivery-types) used
to deliver the Compulsion effect.\
The Effects Dominate and Enthral can override weaker
Compulsion effects including; Calm, Shun, and Fear.
In the event of a Character being affected by Enthral
and Dominate the Enthral effect overrides the
Dominate.

### Calm
This Compulsion effect causes the target to
enter an extremely calm and tranquil state. The target
cannot attack themselves or any other creature
though they will not ignore danger. This effect ends if
the target is attacked.

### Charm
This Compulsion effect causes the target to
view the caster as a trusted friend listening to their
suggestions and not attacking them. This does not grant
the caster any control over the target. This effect ends if
the caster attacks the target.

### Cowardice
This Compulsion effect prevents the
target from using any non-ranged weapon attacks
including effects which are delivered as &lt;Effect>-
Strike.

### Dominate
This Compulsion effect places the target
under the complete control of the caster. They will
follow all orders, even self destructive ones. Please
note that this spell does not force a player to engage
in any activities they are not comfortable with
performing.

### Fear
This Compulsion effect causes the target to
immediately flee the source‘s presence attempting to
break line of sight with them. The target cannot use
any Skills while under this effect. Once the target has
broken line of sight with the source for ten(10)
seconds they may again use their Skills but this effect
remains active unless it ends or is removed. Until it
does, if the target returns to the source's line of sight
they again lose access to all Skills and must flee in
an attempt to once again break line of sight

### Shun
This Compulsion effect prevents the target
from willingly approaching or attacking the Caster.
This effect ends if the Caster attacks the target.

### Silence
This Compulsion effect prevents the target
from speaking or casting Spells with an Incantation.
This effect also ends any Spells, with a duration of
Sustained, the target has in effect. Additionally, the
target cannot intentionally create any sound such as
clapping or using a noise making tool.

### Sleep
This Compulsion effect causes the target to
enter into a deep sleep preventing them from
moving or using any Skills. As soon as it is safe to do
so, the target must lay down as if asleep. The target
is unaware of their surroundings and treated as
[Unconscious](./states-of-living#unconcious).
