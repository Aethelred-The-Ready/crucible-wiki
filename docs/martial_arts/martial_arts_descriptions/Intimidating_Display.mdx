# Intimidating Display
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> 10 Seconds<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Artistry allows the Caster to throw any number of packets. Any creature struck by one or more packets must immediately flee the Caster's presence attempting to break line of sight with them. They cannot use any Skills while under this effect. Once the target has broken line of sight with the Caster for ten(10) seconds they may again use their Skills but this effect remains active unless it ends or is removed. Until it does, if the target returns to the Caster's line of sight they again lose access to all Skills and must flee in an attempt to once again break line of sight.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Lesser](/docs/glossary/delivery-types#lesser) [Physical](/docs/glossary/delivery-types#physical) [Fear](/docs/glossary/compulsion#fear)"<br/>
