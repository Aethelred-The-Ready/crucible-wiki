# Staff
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to wield a Staff in combat. A Staff can only be used to block and can never be used to attack or deliver any effect. For information of the requirements for the Physical Representations for this, and other Weapons, see Chapter 5: Equipment.<br/>
