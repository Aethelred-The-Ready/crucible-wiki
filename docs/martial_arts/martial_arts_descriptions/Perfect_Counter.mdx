# Perfect Counter
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry allows the Caster to cause a single effect delivered as &lt;Effect&gt;-Strike, or any attack causing Weapon Damage to be rebounded against their attacker. This Artistry is not cast in advance, it is simply expended in order to [Reflect](/docs/glossary/reflect) the effect.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Reflect](/docs/glossary/reflect)"<br/>
