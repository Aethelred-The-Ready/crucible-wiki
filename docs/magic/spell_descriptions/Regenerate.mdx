# Regenerate
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell causes the target to begin Regenerating. Upon being affected by this Spell the target may immediately spend a sixty(60)-count to benefit from this effect. At the end of this count the target is restored to maximum Hit Points. When cast on a target that is Dying, the Character's Dying Count is paused for its duration. This effect ends, without effect, if the target is affected by any damaging effect, uses any Skill, or moves faster than a normal walking pace.<br/>
<b>Incantation:</b> "I call upon the Dawn to Regenerate you."<br/>
