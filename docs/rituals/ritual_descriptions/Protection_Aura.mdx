# Protection Aura
<b>Cost:</b> P5 C2 S3 T3<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Protection](/docs/magic/protection_list)<br/>
<b>Target:</b> Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target with the following ability. Once per [Reset](/docs/glossary/reset) the Player may choose to activate this defence to negate a single effect as per the ability Perfect [Ward](/docs/combat/defences#ward). This ability cannot negate effects delivered as [Arcane(-Strike)](/docs/glossary/delivery-types#arcane). The call for this defence is "Ward".<br/>

This Ritual can be cast on a target more than once
