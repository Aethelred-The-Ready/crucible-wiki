# Extend Ritual, Superior
<b>Cost:</b> P6 C4 T6 + Special<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> All<br/>
<b>Target:</b> Any Ritual Effect or Concert.<br/>
<b>Duration:</b> Five(5) Years<br/>
<b>Effect:</b> When cast as the last Ritual in a Ritual Concert, this Ritual extends the duration of all valid Ritual effects in the current target Ritual Concert to five(5) years. This effect consumes two(2) of the Item's Ritual effect slots. This effect also requires a Special Component to be included.<br/>
