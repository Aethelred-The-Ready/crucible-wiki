# Death Strike
<b>School:</b> [Duelist](../duelist_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry allows the Caster to deliver a Weapon Attack which instantly kills the target, causing them to enter their [Death](/docs/glossary/death) Count.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical-Strike](/docs/glossary/delivery-types#physical) [Death](/docs/glossary/death)"<br/>
