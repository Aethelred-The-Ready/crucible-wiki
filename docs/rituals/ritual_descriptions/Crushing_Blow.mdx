# Crushing Blow
<b>Cost:</b> P2 C1 D1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Affliction](/docs/magic/affliction_list), [Conjuration](/docs/magic/conjuration_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Mace<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to deliver an attack causing "20 [Physical-Strike](/docs/glossary/delivery-types#physical) Force".<br/>

This Ritual can be cast on a target more than once
