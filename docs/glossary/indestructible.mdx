# Indestructible

All Items made of [Adamantine](/docs/equipment/special-materials) or
containing one or more [Ritual](/docs/rituals/rituals) effects are
Indestructible. An Indestructible item is Immune to the
effects of [Break](/docs/glossary/break) and [Destroy](/docs/glossary/destroy) &lt;Item&gt;. An Item which is
Indestructible can never be chosen as the target item
for a Break or Destroy &lt;Item&gt; effect unless it is the
only Item in the Character’s possession which
matches the description specified in the effect’s
Delivery Verbal. An Arcane Break will cause the Item
to become unusable until it is Repaired. An [Arcane](/docs/glossary/delivery-types#arcane)
[Destroy](/docs/glossary/destroy) &lt;Item&gt; will cause the target to be Destroyed
normally.
