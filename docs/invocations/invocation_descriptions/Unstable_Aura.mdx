# Unstable Aura
<b>Type:</b> Magic<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) increases the damage the Character causes with a single weapon by one(1). This effect does not stack with the effects of the [Enhance](/docs/glossary/enhance) Weapon Ritual Effect. This effect ends if the item leaves the Caster's possession.<br/>
