# Freezing Grenade
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a Packet attack causing a "[Physical](/docs/glossary/delivery-types#physical) [Bind](/docs/glossary/binding#bind)" to affect the target. Alternatively, the Character may expend a single use of this Skill in order to deliver a Packet attack which causes a &quot;Physical [Pin](/docs/glossary/binding#pin)&quot; effect.<br/>
