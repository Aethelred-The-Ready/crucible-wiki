# Withering Fire
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 0<br/>
<b>Range:</b> Self and Packet<br/>
<b>Duration:</b> Charged (5)<br/>
<b>Effect:</b> This Cantrip grants the Caster five(5) charges of this effect. The Caster may expend one charge to deliver, by packet, two(2) points of [Magic](/docs/glossary/delivery-types#magic) [Body](/docs/glossary/body). As a Cantrip, this effect can be used once, afterwards the Character must Rest in order to regain its use.<br/>
<b>Incantation:</b> None<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "2 [Magic](/docs/glossary/delivery-types#magic) [Body](/docs/glossary/body)" <br/>
