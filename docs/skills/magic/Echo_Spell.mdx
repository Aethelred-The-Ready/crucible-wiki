# Echo Spell
<b>Requirements:</b> Level 1 [Spell Slot](/docs/skills/magic/Spell_Slot.mdx)<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a copy of the last Spell they cast. The Spell must be delivered from memory to use this Skill. This ability must be activated within ten(10) seconds of the initial Spell. The copy is delivered without Incantation and includes all the same options, including any and all [Spellshape](/docs/magic/magichapes)s and other abilities used on the first Spell. The call for this ability is "[Echo](/docs/glossary/echo): &lt;Delivery Verbal of copied Spell&gt;".<br/>
