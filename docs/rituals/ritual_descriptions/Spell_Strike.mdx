# Spell Strike
<b>Cost:</b> P3 C1 E1 S1<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> Any<br/>
<b>Target:</b> Any Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Once per [Reset](/docs/glossary/reset) this weapon may be used to deliver a single Spell with a range of Packet from the [Caster](/docs/rituals/ritual_glossary#Caster)'s memory as an [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) instead of its normal Delivery Type. The Delivery Type of the attack changes to match that of the Spell.<br/>
