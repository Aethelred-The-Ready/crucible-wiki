# Planar Attunement
<b>Cost:</b> P1 C1 + P1 per additional target<br/>
<b>Type:</b> Alchemy, Magic<br/>
<b>School:</b> [Conjuration](/docs/magic/conjuration_list), [Protection](/docs/magic/protection_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> The Caster and One additional target per additional Power Component expended.<br/>
<b>Duration:</b> Event [Cannot be Extended]<br/>
<b>Effect:</b> This Ritual grants all targets [Immunity](/docs/glossary/immunity) to the harmful passive planar effects of the chosen plane. This effect cannot be extended and expires at the end of the Event. The maximum number of targets of this Ritual is equal to the twice number of Casters participating in the Ritual's casting.<br/>
