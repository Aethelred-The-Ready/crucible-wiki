# Imbue Skill
<b>Cost:</b> P3 C2 S2 + See Text<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Item or Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> As part of casting this Ritual the [Caster](/docs/rituals/ritual_glossary#Caster) chooses one Skill they possess. Only Skills which are usable "Once per [Reset](/docs/glossary/reset)" can be Imbued. Alchemy Slots, Martial Arts Slots, Spell Slots, and Heritage Skills cannot be Imbued by this Ritual Effect. The same Skill can never be Imbued into a target more than once.

 The following Skills may be Imbued into an [Item](/docs/rituals/ritual_glossary#Item) but require the Character to have at least one(1) Rank in the Skill in order to use the Imbued Skill. These Skills include; Create Cauldron, Create Flask, Create [Diagnose](/docs/skills/crafting/potion), Create [Scroll](/docs/rituals/ritual_glossary#Scroll), Create Wand, Defensive Roll, Rune Carving, and Smithing.

 This Ritual requires an additional number of Power Components equal to one half the Skill Point cost, at Priority A, of the Skill to be stored rounded up. This Ritual imbues the ability to use the chosen Skill into the target. The Character who is attuned to the item, or is the target of this effect, may use the imbued skill once per Reset. The call to use a Skill which is imbued by this effect is "Activate &lt;Skill Verbal&gt;".<br/>

This Ritual can be cast on a target more than once
