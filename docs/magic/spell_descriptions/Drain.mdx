# Drain
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Spell prevents the target from running or using any Skills until the effect ends or is removed.<br/>
<b>Incantation:</b> "I Curse you to be Drained."<br/>
