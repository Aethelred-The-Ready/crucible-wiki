# Spellbreaker
<b>School:</b> [Slayer](../slayer_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Artistry instantly removes all effects which were delivered as Magic(-Strike) from the target.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical-Strike](/docs/glossary/delivery-types#physical) [Dispel](/docs/glossary/dispel) Magic"<br/>
