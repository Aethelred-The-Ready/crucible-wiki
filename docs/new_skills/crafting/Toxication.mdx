# Toxication
<b>Requirements:</b> Level 5 Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may [Resist](/docs/glossary/resist) an effect, by which they are struck, which would remove one or more Poison effects such as [Remove](/docs/glossary/remove) Poison or [Dispel](/docs/glossary/dispel) Poison.<br/>
