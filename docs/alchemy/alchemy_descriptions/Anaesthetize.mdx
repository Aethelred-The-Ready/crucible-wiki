# Anaesthetize
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Alchemy causes the target to fall into a deep sleep preventing them from moving or using any Skills. The target will lie down wherever they are as soon as it is safe to do so. The target is not aware of their surroundings and is not considered Conscious. This Alchemy is removed by any effect which removes Compulsion or [Poison](/docs/glossary/delivery-types#poison)s.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Sleep](/docs/glossary/compulsion#sleep)"<br/>
