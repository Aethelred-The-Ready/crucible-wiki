# Master Alchemist
<b>Requirements:</b> [Alkahestry](/docs/new_skills/crafting/Alkahestry.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character one of the following two options;

Practised Alchemist: The Character counts as an additional Caster for the purposes of all Ritual Alchemy. Additionally, the number of Invocations the Character may cast each Reset is increased by one(1). Each additional time this option is taken the Character acts as an additional Caster and can cast an additional Invocation each Reset.

Eschew Components: The Character chooses a single Component type, other than Power. The Character reduces the total number of Components needed to cast the Ritual by one(1) to a minimum of one(1). Each additional time this option is taken the Character must choose a new Component type. If A Character has already taken this Skill for every component type they can no longer take this branch of the Skill.<br/>
