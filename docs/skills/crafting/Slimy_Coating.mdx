# Slimy Coating
<b>Requirements:</b> Level 1 Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a single Alchemy as a [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) using a Weapon, instead of a Packet, with which they are proficient. The Character does not need a free hand to cast the Alchemy if they are wielding a Weapon.<br/>
