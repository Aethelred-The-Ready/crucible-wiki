# Spell Counter
<b>Cost:</b> P4 C2 E2 S2 T1<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> None<br/>
<b>Target:</b> Iron Sword<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. While wielding this weapon, the Character may also expend a use of the Counter Skill to [Reflect](/docs/glossary/reflect) any Weapon or Packet delivered effect delivered as [Magic(-Strike)](/docs/glossary/delivery-types#magic). The call for this ability is "Reflect".<br/>
