<b>Requirements:</b> None\
Once per [Reset](../../glossary/reset), the Character may negate any attack delivered, by weapon or packet, as &lt;Effect&gt;-Strike or Physical by which they are struck. The call for this ability is “Parry”.\
If the Character has the Bodyguard Skill they can use this ability to negate an applicable attack which strikes another target within their Weapon's reach. This Skill does not count as a prerequisite for any other Skill.
