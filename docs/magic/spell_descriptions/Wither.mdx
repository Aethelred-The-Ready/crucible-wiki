# Wither
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 minutes<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Spell delivers a [Magic](/docs/glossary/delivery-types#magic) [Cripple](/docs/glossary/curse#cripple) effect affecting the limb of the Caster's choice. A Crippled arm cannot be used for any Skills and cannot hold any items. A Crippled leg cannot be used to walk and prevents the target from moving faster than a slow, limping walking pace. The target cannot hop. If both legs are Crippled the target can only kneel in place.<br/>
<b>Incantation:</b> "I Curse you with Withering."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Cripple](/docs/glossary/curse#cripple) &lt;Limb&gt;" <br/>
