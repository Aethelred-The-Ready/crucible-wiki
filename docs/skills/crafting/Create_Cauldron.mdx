# Create Cauldron
<b>Requirements:</b> [Create Flask](/docs/skills/crafting/Create_Flask.mdx) [Create Potion](/docs/skills/crafting/Create_Potion.mdx) 20<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may create a Cauldron which contains a single Technique, with a Range of [Contingency](/docs/glossary/delivery-types#touch) or Packet, which is an Alchemy or from one of the following Schools of [Magic](/docs/glossary/delivery-types#magic); Protection, Restoration, Transmutation. The caster must be able to cast the stored Technique . The creator may set up the Cauldron as an immovable object from which anyone may spend a ten(10)-count to role-play drawing from, and imbibing a portion of the Cauldron gaining the benefits of the contained Technique. Any number of Characters may benefit from the Cauldron but a Character may benefit from a single Cauldron no more than once per Reset period. A Cauldron ends if the Cauldron is Destroyed or its creator sets up a second Cauldron.

A Cauldron is a container which can hold a minimum of two(2) litres of liquid.

In order to use this Skill the Character must have access to a [Diagnose](/docs/skills/crafting-skills/potion) Laboratory. All Cauldrons expire at the end of the Event.<br/>
