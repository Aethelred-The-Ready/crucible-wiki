# Liquid Light
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Day<br/>
<b>Effect:</b> This Spell creates an Alchemical Light source which allows the use of a diffused flash light, lantern, glow stick or similar light source. A light source may be disqualified from use if it is too bright. The decision as to whether or not a light can be used is up to the Marshal.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Lantern](/docs/glossary/lantern)"<br/>
