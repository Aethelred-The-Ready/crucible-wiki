# Unravelling Weapon
<b>Cost:</b> P4 D3 S2<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> None<br/>
<b>Target:</b> Iron Axe<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to deliver a "[Physical-Strike](/docs/glossary/delivery-types#physical) [Vanquish](/docs/glossary/vanquish) Fae".<br/>

This Ritual can be cast on a target more than once
