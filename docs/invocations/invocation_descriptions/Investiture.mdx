# Investiture
<b>Type:</b> All<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Invocation requires both the Caster and Target Character to to be standing fully within a target [Protective Circle](/docs/rituals/ritual_glossary#protective circle) in which the Caster is Invested.

 When performed as an Alchemy Invocation the Circle must be an Alchemical Fountain. When performed as a [Magic](/docs/glossary/delivery-types#magic) Invocation the Circle must be a Magic Circle. When performed as a Smithing Invocation the Circle must be a Forge of Kings.

 This Invocation grants the Target Character an Investiture into the target Circle.<br/>
