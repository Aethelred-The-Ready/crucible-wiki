# Acid Bomb
<b>Requirements:</b> [Acid Grenade](/docs/skills/expertise/Acid_Grenade.mdx) 3 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a Packet attack causing "20 [Physical](/docs/glossary/delivery-types#physical) Acid" damage to the target. The Character may throw any number of Packets when using this Skill but must throw all Packets with the same hand.<br/>
