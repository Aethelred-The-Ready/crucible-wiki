# Iron Gilding
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) grants the Caster three(3) Charges. The Caster may expend one(1) Charge to negate a single [Compulsion](/docs/glossary/compulsion) effect by which they are struck. The call for this effect is "[Ward](/docs/glossary/Ward)".<br/>
