# Sculpt Claw
<b>Cost:</b> P1 S1 T1<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> [Restoration](/docs/magic/restoration_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual causes the target's [Claws](/docs/glossary/claw), if any, to count as either an Axe, Sword, or Blunt Weapon. If cast a second time, on the same target, any Natural Weapon wielded by the target in their off-hand instead counts as either an Axe, Sword, or Blunt Weapon. Once this Ritual has been performed on the target they may benefit from Ritual effects which target that particular type of weapon. Without this Ritual effect a target is unable to benefit from the effects of any Rituals which target a specific type of weapon, such as Blood Drinker, but may still benefit from Rituals which target any type of weapon such as [Enhance](/docs/glossary/enhance) Weapon.<br/>

This Ritual can be cast on a target more than once
