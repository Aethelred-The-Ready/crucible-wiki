# Shadow Walk
<b>Type:</b> Crafting, Magical, Shadow<br/>
<b>Benefit:</b> This Intervention allows the Character to deliver against all willing Adventurers an [Arcane](/docs/glossary/delivery-types#arcane) [Teleport](/docs/glossary/teleport). This ability follows all other rules for the Spell Teleport. The call for this ability is "[Sound of Voice](/docs/glossary/delivery-types#sound-of-voice): All Willing Adventurers, Arcane Teleport!"<br/>
