# Extra Trap
<b>Requirements:</b> Any Trap<br/>
<b>Benefit:</b> For every Rank a Character has in this Skill, they may place, and arm, a single additional Trap. This Skill even allows a Character to have multiple Traps of the same type in place at once. Normally a Character is limited to one(1) Trap of each type at a time. It does not grant any additional uses of any Trap Skill.<br/>
