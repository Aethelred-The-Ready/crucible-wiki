# Toxin Grenade
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a Packet attack causing "20 [Poison](/docs/glossary/delivery-types#poison) [Body](/docs/glossary/body)" damage to the target. Alternatively, the Character may expend a single use of this Skill in order to deliver a Packet attack which causes a &quot;[Physical](/docs/glossary/delivery-types#physical) [Weakness](/docs/glossary/curse#weakness)&quot; effect.<br/>
