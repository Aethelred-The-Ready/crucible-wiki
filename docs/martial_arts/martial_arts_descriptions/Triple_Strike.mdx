# Triple Strike
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> Charged (3)<br/>
<b>Effect:</b> This Artistry grants the Caster the ability to deliver three(3) [Physical-Strike](/docs/glossary/delivery-types#physical)s, each causing twenty(20) points of damage of the Weapon Type of the weapon used to deliver them. Once this Artistry is cast, the Caster has ten(10) seconds to use all charges or any remaining charges are lost. If this Artistry benefits from the Assassin Tradition, Echo, or similar effects, it applies to all Charges, but the Character must meet any requirements for the benefit for each attack.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "20 [Physical-Strike](/docs/glossary/delivery-types#physical) &lt;Weapon Type&gt;" x3<br/>
