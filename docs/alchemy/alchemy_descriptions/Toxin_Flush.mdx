# Toxin Flush
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Alchemy instantly removes all harmful effects from the target which would be removed by the target becoming Dead as well as [Enthral](/docs/glossary/enthral). The target's Player makes the determination as to which effects are harmful.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Cleanse](/docs/glossary/cleanse)"<br/>
