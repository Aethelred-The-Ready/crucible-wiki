# Channel Spell
<b>Requirements:</b> Level 1 [Spell Slot](/docs/skills/magic/Spell_Slot.mdx)<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a single Spell as an [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) using a Weapon, instead of a Packet, with which they are proficient. The Delivery Type used to deliver the effect is determined by the Delivery Type of the Spell. For example, if the Spell allows the Character to deliver a [Magic](/docs/glossary/delivery-types#magic) [Sleep](/docs/glossary/compulsion#sleep) effect, the call for this ability is "[Magic-Strike](/docs/glossary/delivery-types#magic) Sleep". If the effect causes "10 [Elemental](/docs/glossary/delivery-types#elemental) Fire" damage, the Channelled effect is "10 [Elemental-Strike](/docs/glossary/delivery-types#elemental) Fire". The Character does not need a free hand to cast the Spell if they are wielding a Weapon with which they are Proficient. For more information on Channelling Spells see Page 100.<br/>
