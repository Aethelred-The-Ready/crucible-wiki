# Grounded Armour
<b>Cost:</b> P2 C1 E2<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> Smithing<br/>
<b>Target:</b> Iron Armour or Iron Shield<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target armour with the following ability. Once per [Reset](/docs/glossary/reset), the [Item](/docs/rituals/ritual_glossary#Item) can negate a single effect delivered as [Magic(-Strike)](/docs/glossary/delivery-types#magic). The Call for this ability is "[Ward](/docs/combat/defences#ward)".<br/>

This Ritual can be cast on a target more than once
