# Mortal Strike
<b>Cost:</b> P4 D2 S2<br/>
<b>Type:</b> Smithing<br/>
<b>School:</b> None<br/>
<b>Target:</b> Adamantine Sword<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to deliver an attack causing "[Physical-Strike](/docs/glossary/delivery-types#physical) [Frailty](/docs/glossary/curse#frailty)".<br/>

This Ritual can be cast on a target more than once
