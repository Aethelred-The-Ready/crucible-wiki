# Repel

This effect forces the target to immediately
take ten(10) steps away from the source of this effect.
If it is not possible for the Player to safely do so they
must move as far away as possible. For example it
cannot force a Player to walk into a hazardous or
unsafe area, but a Character can be pushed into an
in-game hazard such as a trap or through a portal.
This effect lasts ten(10) seconds.
