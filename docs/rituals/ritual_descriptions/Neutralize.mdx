# Neutralize
<b>Cost:</b> P4 D2 T2<br/>
<b>Type:</b> Alchemy<br/>
<b>School:</b> None<br/>
<b>Target:</b> Ritual Alchemical Effect, Item or Creature<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Ritual [Destroys](/docs/glossary/destroy) all Ritual Alchemy in effect on the target as well as removing all effects delivered as [Poison(-Strike)](/docs/glossary/delivery-types#poison) from the target.<br/>
