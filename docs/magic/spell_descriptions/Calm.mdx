# Calm
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Spell causes the target to enter an extremely calm and tranquil state. The target cannot attack themselves or any other creature though they will not ignore danger. This effect ends if the target is attacked.<br/>
<b>Incantation:</b> "I Compel you to be Calm."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Calm](/docs/glossary/compulsion#calm)"<br/>
