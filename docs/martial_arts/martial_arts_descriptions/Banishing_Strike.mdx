# Banishing Strike
<b>School:</b> [Slayer](../slayer_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry forces the target [Extraplanar creature or Elemental](/docs/lore/planes-of-existance) back to its home plane. A creature which has been affected by this effect cannot return to the plane from which it was Banished for twenty-four(24) hours.

 This Artistry only functions on Hymira and will fail if cast on any other Plane.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical-Strike](/docs/glossary/delivery-types#physical) [Banish](/docs/glossary/banish)"<br/>
