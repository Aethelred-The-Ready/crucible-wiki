# Master's Watch
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) must be cast on, and within, a valid Circle. All items within the Circle gain [Immunity](/docs/combat/defences#immune) to [Break](/docs/glossary/break) and [Destroy](/docs/glossary/destroy) so long as they remain in the Circle. This effect ends if the Caster leaves the Circle or enters their [Death](/docs/glossary/death) Count.<br/>
