# Intimidating Shout
<b>School:</b> [Slayer](../slayer_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Artistry prevents the target from willingly approaching the Caster or attacking the Caster. This effect ends if the Caster attacks the target.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Shun](/docs/glossary/compulsion#shun)"<br/>
