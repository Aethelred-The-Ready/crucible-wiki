# Ranger Bond, Protector
<b>Cost:</b> P2 C2 S1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Protection](/docs/magic/protection_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Leather Armour<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual requires the target Suit of Leather Armour to include the front of the torso and at least four other areas. This effect improves the value of each piece of the suit to that of Chainmail. If this Ritual is cast three(3) times on the same target, the value of each piece of the suit is increased to that of Plate.

 This Ritual takes up one(1) Ritual Effect slot if it is cast once and two(2) if it is cast thrice.<br/>

This Ritual can be cast on a target more than once
