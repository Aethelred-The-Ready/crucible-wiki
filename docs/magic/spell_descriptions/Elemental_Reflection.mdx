# Elemental Reflection
<b>School:</b> [Conjuration](../conjuration_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell causes the next effect delivered as [Elemental-Strike](/docs/glossary/delivery-types#elemental) by which the target is struck to be reflected back at the attacker. If the effect is reflected twice it is instead negated.<br/>
<b>Incantation:</b> "I grant you the protection of Elemental Reflection."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Elemental](/docs/glossary/delivery-types#elemental) [Reflect](/docs/glossary/reflect)ion"<br/>
