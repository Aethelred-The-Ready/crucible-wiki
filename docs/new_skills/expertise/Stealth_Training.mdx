# Stealth Training
<b>Requirements:</b> See Text<br/>
<b>Benefit:</b> The Character increases the Weapon Damage call of all Weapons they wield when behind their target, by two(2) for each Rank they have in this Skill. A Character is considered to be behind their target if they are physically standing behind them and able to see both of their shoulder blades. There are two ways to purchase this skill. The first is to trade in a number of ranks Stealth Prowess equal to their number of ranks in Stealth Training plus five(5). The Character does not receive any build back for the traded in Stealth Prowess ranks as this is built into the cost for the Skill. The second is to purchase the Skill outright at a cost which is increased each time the Character purchases another Rank. For example, the cost for 3 Ranks of Stealth Training for a Character with Priority A in Expertise is 54 (16 + 18 + 20).<br/>
