# Absorb Poison
<b>Requirements:</b> [Slime Armour](/docs/new_skills/crafting/Slime_Armour.mdx) 1<br/>
<b>Benefit:</b> The Character may [Absorb](/docs/glossary/absorb) Alchemy which they Touch Cast, from memory, on themselves. This Alchemy, instead of its normal effect, restores an amount of [Natural Armour](/docs/equipment/non-physical-armour) equal to five(5) times the level of the expended Alchemy Slot. The Alchemy's effect must be one which is Delivered as Poison. The call for this use is "&lt;Delivery Verbal&gt;, Absorb". <br/>
