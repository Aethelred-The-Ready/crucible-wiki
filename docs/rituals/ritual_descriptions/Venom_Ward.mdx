# Venom Ward
<b>Cost:</b> P3 C1 D1 E1 T1<br/>
<b>Type:</b> Alchemy, Magic<br/>
<b>School:</b> [Protection](/docs/magic/protection_list)<br/>
<b>Target:</b> Any Item or Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target with the following ability. Once per [Reset](/docs/glossary/reset), the Character, or wielder of the item, may negate a single effect delivered as [Poison(-Strike)](/docs/glossary/delivery-types#poison). The call for this ability is "[Ward](/docs/glossary/Ward)".<br/>
