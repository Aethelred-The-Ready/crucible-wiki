# Courageous Voice
<b>School:</b> [Guardian](../guardian_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Self and Touch<br/>
<b>Duration:</b> Concentration<br/>
<b>Effect:</b> This Artistry grants the Caster the ability to deliver, by [Contingency](/docs/glossary/delivery-types#touch), a [Physical](/docs/glossary/delivery-types#physical) [Remove](/docs/glossary/remove) [Fear](/docs/glossary/compulsion#fear) effect at will. This effect ends if the Caster goes ten(10) seconds without affecting a new target or enters a state where they are unable to use Skills. No target can benefit from this effect more than once.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Remove](/docs/glossary/remove) [Fear](/docs/glossary/compulsion#fear) … Physical Remove Fear"<br/>
