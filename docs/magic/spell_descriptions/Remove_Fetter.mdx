# Remove Fetter
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell removes the [Fetter](/docs/glossary/curse#fetter) effect from the target. Since a target cannot have multiple instances of the same effect, this removes all Fetter from the target.<br/>
<b>Incantation:</b> "I call upon the Dusk to Remove Fetter."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Remove](/docs/glossary/remove) [Fetter](/docs/glossary/curse#fetter)"<br/>
