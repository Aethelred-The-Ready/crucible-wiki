# Disorienting Shout
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This Artistry prevents the target from running or even standing up right. The target cannot use any Skills and, additionally, cannot move without crawling.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Vertigo](/docs/glossary/vertigo)"<br/>
