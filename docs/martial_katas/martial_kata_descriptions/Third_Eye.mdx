# Third Eye
<b>School:</b> [Guardian](/docs/martial_arts/guardian_list)<br/>
<b>Effect:</b> This Kata grants the Character three(3) Charges of this ability. The Character may expend one(1) Charge to avoid a Packet or Weapon delivered effect by which they are struck to which the [Dodge Skill](/docs/skills/expertise/dodge) would be an applicable defence. The call for this effect is "Dodge".

 Alternatively, the Character may expend one(1) Charge and a use of the Dodge Skill, or two(2) Charges of this ability, in order to avoid any effect to which the Skill Evasion is applicable. The call for this use of this ability is "Evasion".<br/>
