This effect automatically negates the next effect, to
which it is applicable, by which the target is struck to
rebound against the attacker. A Character may accept
effects which are [Touch Cast](/docs/glossary/delivery-types#touch) through any Reflect(ion)
effect. For example, an Elemental Reflection will
affect any effect which is delivered as [Elemental(-Strike)](/docs/glossary/delivery-types#elemental). A [Binding](/docs/glossary/binding) Reflection will affect any effect which is a Binding effect regardless of [Delivery Type](/docs/glossary/delivery-types).
A Lightning Reflection will affect any effect which
causes Lightning damage. Finally a [Death](/docs/glossary/death) Reflection
will affect any effect which causes a Death effect
regardless of Delivery Type. The call for this ability is
“Reflect &lt;Effect&gt;”.
