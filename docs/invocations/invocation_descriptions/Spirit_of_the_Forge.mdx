# Spirit of the Forge
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Concentration<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) targets a Portable Forge. The target Portable Forge counts as a Town Forge until one of the following events occur; the Character uses any Skill other than Smithing, the targeted Portable Forge is moved, the Caster moves more than three(3) metres from the Forge or the Caster is subjected to any effect which would Disrupt Spell casting.<br/>
