# Modify Memory
<b>Cost:</b> P2 C2 D1 S1<br/>
<b>Type:</b> Alchemy, Magic<br/>
<b>School:</b> [Affliction](/docs/magic/affliction_list)<br/>
<b>Target:</b> Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual allows the [Caster](/docs/rituals/ritual_glossary#Caster) to modify a specific memory of the target. While this Ritual can, with permission of the target's Player, affect a more general memory, it normally is limited to a single hour which has occurred on the same Day in which this Ritual is cast. The Caster can choose one of the following three effects; Amnesia: The target forgets the target memory. Modified: The target remembers the memory slightly differently with persons or events being as described by the Caster. In this case the Caster must describe the altered memory in thirty(30) words or fewer. Fabricated: The memory is completely different. In this case the Caster must describe the new memory in twenty(20) words or fewer.

 This effect becomes permanent if it is not Destroyed before the end of the Event during which it was cast.<br/>

This Ritual can be cast on a target more than once
