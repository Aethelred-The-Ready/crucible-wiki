# Vital Elixir
<b>Type:</b> Alchemy<br/>
<b>Duration:</b> Charged (3)<br/>
<b>Effect:</b> This Invocation grants the Caster three(3) Charges. The Caster may expend one(1) Charge to negate a single effect, by which they are struck, which causes [Body](/docs/glossary/body) damage. The call for this effect is "[Ward](/docs/combat/defences#ward)".<br/>
