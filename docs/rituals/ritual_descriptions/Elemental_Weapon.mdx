# Elemental Weapon
<b>Cost:</b> P2 C1 E2<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> [Conjuration](/docs/magic/conjuration_list)<br/>
<b>Target:</b> Any Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> As part of Casting this Ritual the caster chooses one of the following Damage Types;  Chaos, Destruction, Dream, Essence, Fire, Ice, Light, Lightning, Order, Reason, Shadow, or Stone. The wielder of the target Weapon may use the chosen Damage Type in addition to the Weapon's normal Weapon Type. Additionally, when using an [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) which uses the Weapon's Weapon Type, they may instead replace the Weapon Type with the Chosen Damage Type.<br/>

This Ritual can be cast on a target more than once
