# Shadow Duplication
<b>Cost:</b> P3 C3 S1 T2<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> [Conjuration](/docs/magic/conjuration_list)<br/>
<b>Target:</b> Thrown Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual imbues the target weapon with the following ability. Whenever a weapon with this Ritual effect is thrown, the Character may throw one(1) additional [Avoidance Armour](/docs/equipment/weapons), which must be identical to the weapon on which this Ritual is cast. Any creature struck by either Weapon is affected once by the attack. This additional weapon, and any others the Character may throw, must be thrown with the same hand and must be thrown at the same time.<br/>
