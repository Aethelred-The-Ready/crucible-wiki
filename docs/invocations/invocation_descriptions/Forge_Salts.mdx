# Forge Salts
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Concentration<br/>
<b>Effect:</b> This [Invocation](/docs/invocations) allows the Character to perform Smithing abilities without the need for a Portable Forge. This Invocation ends when the Character after five(5) minutes or until the Character uses any Skill other than Smithing.<br/>
