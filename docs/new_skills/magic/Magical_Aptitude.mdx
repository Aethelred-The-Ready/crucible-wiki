# Magical Aptitude
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character is able to learn how to cast Spells. Additionally the Character may perform any of the following actions on a sixty(60)-count; 1) Detect the presence of, but no other information about the, magic on an item they are touching, 2) Identify the Spells contained in any number of [Diagnose](/docs/skills/crafting-skills/scroll)s, or 3) Identify the Spells contained in any number of [Diagnose](/docs/skills/crafting-skills/potion)s.

If the Character has both this Skill and the Skill Sense [Magic](/docs/glossary/delivery-types#magic) they may identify what School(s) of Magic are present on the item when using the Detect portion of this Skill.<br/>
