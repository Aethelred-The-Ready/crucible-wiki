# Imbue Spell
<b>Cost:</b> P2 C2 E2 + See Text<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> Any (See Text)<br/>
<b>Target:</b> Any Item or Spirit<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> As part of casting this Ritual the [Caster](/docs/rituals/ritual_glossary#Caster) chooses one Spell they can cast, with a Range other than Self, from memory. This Ritual requires an amount of additional Power equal to one third the level of the Spell to be stored rounded up. This Ritual imbues the ability to cast the chosen Spell into the target. The Caster cannot use their own Skills to modify the Spell in any way. The Character who is attuned to the item, or is the target of this effect, may cast the Imbued Spell once per [Reset](/docs/glossary/reset). The call to use a Spell which is Imbued by this effect "Activate &lt;Incantation&gt; &lt;Delivery Verbal&gt;". A Character cannot use their own Skills to modify a Spell which is cast using an item.<br/>

This Ritual can be cast on a target more than once
