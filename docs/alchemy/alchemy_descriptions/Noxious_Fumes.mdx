# Noxious Fumes
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Alchemy affects the target with a "[Poison](/docs/glossary/delivery-types#poison) [Shun](/docs/glossary/compulsion#shun)" effect preventing the target from willingly approaching the Caster or attacking the Caster. This effect ends if the Caster attacks the target.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Shun](/docs/glossary/compulsion#shun)"<br/>
