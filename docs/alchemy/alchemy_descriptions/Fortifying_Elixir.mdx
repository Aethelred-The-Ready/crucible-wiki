# Fortifying Elixir
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Alchemy grants the target five(5) Fortification Points. These Fortification Points are always the first lost due to damage. Multiple effects which grant Fortification Points do not stack.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Fortify](/docs/glossary/fortify) 5"<br/>
