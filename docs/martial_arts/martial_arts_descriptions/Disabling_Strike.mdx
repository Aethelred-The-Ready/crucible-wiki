# Disabling Strike
<b>School:</b> [Duelist](../duelist_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Artistry allows the Caster to deliver a [Physical](/docs/glossary/delivery-types#physical)-Strike [Cripple](/docs/glossary/curse#cripple) effect affecting the limb of the Caster's choice. A Crippled arm cannot be used for any Skills and cannot hold any items. A Crippled leg cannot be used to walk and prevents the target from moving faster than a slow, limping walking pace. The target cannot hop. If both legs are Crippled the target can only kneel in place.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical)-Strike [Cripple](/docs/glossary/curse#cripple) &lt;Limb&gt;"<br/>
