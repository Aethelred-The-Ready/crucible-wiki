# Shadow Duplication
<b>Type:</b> Shadow<br/>
<b>Benefit:</b> Upon activating this Intervention, the Character gains the following ability; Whenever the Character uses the [Dodge Skill](/docs/skills/expertise/dodge), the Character goes Out of Game for ten(10) Steps. The Character must make all ten(10) of these steps immediately and cannot stop until they have taken all ten(10). Whenever the Character uses the Evasion Skill, they gain the same benefits they would if they used a Dodge but they, additionally, also benefit from an [Arcane](/docs/glossary/delivery-types#arcane) [Refit Avoidance Armour](/docs/glossary/refit). This ability cannot be used to reach areas the Character could not reach normally. This effect ends at the End of Combat.<br/>
