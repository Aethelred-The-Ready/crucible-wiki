# Ritual Magic
<b>Requirements:</b> Level 9 [Spell Slot](/docs/skills/magic/Spell_Slot.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character the ability to cast [Ritual Magic](/docs/rituals). Upon gaining this Skill the Character can act as the Primary Caster, or as a Secondary Caster, for any Ritual Magic. Additionally, the Character gains the ability to cast Invocations. See Chapter 8: Rituals for more information on casting Ritual Magic and Invocations.<br/>
