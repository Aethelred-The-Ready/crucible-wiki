# False Vitality
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This Spell appears to return a Dead creature to life, however it only lasts five(5) minutes, after which the target will again die, restarting their [Death](/docs/glossary/death) count.

 This effect returns the target to life at one(1) Hit Point. While under the effects of this Spell the target is Conscious and able to act and use Skills normally. If this effect is [Remove](/docs/glossary/remove)d or [Dispel](/docs/glossary/dispel)led the target immediately restarts their Death Count. A [Life](/docs/glossary/life) effect received by the target before this effect ends removes it without causing the target to die.<br/>
<b>Incantation:</b> "I Curse you with False Vitality."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [False Vitality](/docs/glossary/false-vitality)"<br/>
