# First Martial Arts School
<b>Requirements:</b> Level 1 [Martial Arts Slot](/docs/skills/fighting/Martial_Arts_Slot.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character access to their first Martial Arts School. The Character is able to expend their Martial Arts Slots to use the Martial Arts which belong to this school. See [Spellcasting](/docs/magic/spellcasting) for more information on Martial Arts.<br/>
