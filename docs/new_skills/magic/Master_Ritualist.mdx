# Master Ritualist
<b>Requirements:</b> [Ritual Magic](/docs/new_skills/magic/Ritual_Magic.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character one(1) of the following two(2) options; Practised Ritualist: The Character counts as an additional Caster for the purposes of all [Ritual Magic](/docs/rituals). Additionally, the number of Invocations the Character may cast each Reset is increased by one(1). Each additional time this option is taken the Character acts as an additional Caster and can cast an additional Invocation each Reset. Eschew Components: The Character chooses a single Component type, other than Power. The Character reduces the total number of Components needed to cast the Ritual by one(1) to a minimum of one(1). Each additional time this option is taken the Character must choose a new Component type. If A Character has already taken this Skill for every component type they can no longer take this branch of the Skill.<br/>
