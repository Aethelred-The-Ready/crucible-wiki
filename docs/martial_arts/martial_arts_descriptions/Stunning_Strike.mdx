# Stunning Strike
<b>School:</b> [Duelist](../duelist_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 6<br/>
<b>Range:</b> Strike<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Artistry causes the target to enter into a magical sleep preventing them from moving or using any Skills. As soon as it is safe to do so, the target must lay down as if asleep. The target is not considered Conscious.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical)-Strike [Sleep](/docs/glossary/compulsion#sleep)"<br/>
