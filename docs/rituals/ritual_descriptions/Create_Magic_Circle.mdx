# Create Magic Circle
<b>Cost:</b> P5 C2 E2 S2 T2<br/>
<b>Type:</b> Magic<br/>
<b>School:</b> Any School of Magic<br/>
<b>Target:</b> Any Circle<br/>
<b>Duration:</b> Two(2) Years<br/>
<b>Effect:</b> This Ritual transforms the target [Circle](/docs/rituals/ritual_glossary#Circle) into a [Protective Circle](/docs/rituals/ritual_glossary#protective-circle) of one of the following types; [Binding](/docs/glossary/binding): The number of Services provided by any creature Summoned into this Circle is increased by one(1). Creation: The Power [Component](/docs/rituals/ritual_glossary#Component) cost of any [Ritual Magic](/docs/rituals) cast in this Circle is reduced by one(1) to a minimum of one(1). Knowledge: Anyone invested may [Identify](/docs/invocations/identify) any magical effect within the Circle. Resurrection: Anyone invested may Resurrect a dead character whose spirit has travelled to the Circle.

 Anyone in the Circle for the casting gains an Investiture into the Circle allowing them to enter or leave at will as well as allowing others to do so. Any creature inside of the Circle is [Immune](/docs/combat/defences#immune) to all effects which originate from outside it.

 Multiple castings of this Ritual on the same Circle can be done. Each additional casting grants the target Circle one additional functions outlined above and grants the Circle a [Ward](/docs/glossary/Ward) against the next [Break](/docs/glossary/break) or [Destroy](/docs/glossary/destroy) Magic effect by which it is targeted. These Wards are replenished at the end of the Day.

 This Ritual cannot target a Circle under the effects of the Ritual Create Alchemical Fountain, or Create Forge of Kings.<br/>

This Ritual can be cast on a target more than once
