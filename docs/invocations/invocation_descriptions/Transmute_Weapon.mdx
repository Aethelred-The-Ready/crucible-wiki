# Transmute Weapon
<b>Type:</b> Alchemy<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This Invocation changes the Weapon Type of the target Weapon to one of the following; [Iron](/docs/equipment/special-materials), Normal, or [Silver](/docs/equipment/special-materials). This effect ends if the item leaves the Caster's possession. As long as this Invocation is in effect, the Alchemist can spend one(1) minute to change the Weapon Type to any other valid option.<br/>
