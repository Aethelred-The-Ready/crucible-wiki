# Frenzy
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may either [Resist](/docs/glossary/resist) a single [Berserk](/docs/glossary/berserk) effect by which they are struck, the call for which is "Resist. Physical [Vorpal](/docs/glossary/vorpal) 5", or choose to activate this Skill at any time. When this Skill is activated at the Character's discretion the call is "Physical Vorpal 5".<br/>
