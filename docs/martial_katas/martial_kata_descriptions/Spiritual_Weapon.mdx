# Spiritual Weapon
<b>School:</b> [Duelist](/docs/martial_arts/martial_arts#school), [Slayer](/docs/martial_arts/martial_arts#school)<br/>
<b>Effect:</b> This Kata grants the Character three(3) Charges of this ability. The Character may expend one(1) Charge to deliver a Packet attack causing an amount of [Magic](/docs/glossary/delivery-types#magic) Force damage equal to the combined number of Ranks the Character has in Weapon Training and Stealth Training. The Character may throw any number of Packets when using this ability. Any Character struck by one(1), or more, packets is affected by this effect.<br/>
