# Elixir of Lies
<b>Cost:</b> P2 C1 D1 S2<br/>
<b>Type:</b> Alchemy<br/>
<b>School:</b> None<br/>
<b>Target:</b> None<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This effect creates a special elixir which renders its imbiber into a brief, but highly suggestible state. Once consumed, the effects of this Ritual take effect on the imbiber as follows; The target immediately forgets all events which have occurred in the last hour. The [Caster](/docs/rituals/ritual_glossary#Caster) may describe, in ten(10) words or fewer, an alternate memory. If the Caster describes an alternate memory the target will believe it completely. If this effect is not Destroyed by the end of the Event, the memories become permanent.

 The Elixir created by this Ritual expires at the end of the Event in which it was cast.<br/>
