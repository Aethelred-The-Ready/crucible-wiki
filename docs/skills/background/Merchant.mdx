# Merchant
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains one(1) Rank in the Merchant Skill as well as a single Merchant Sub-Skill for which they meet the Requirements. Additionally, for each Rank the Character has in this Skill they gain a single entry for the Merchant Draw. <br/>

Category: [Background](./background-skills)

The Merchant has learned to trade in a variety of
crafts and materials. Their efforts have been
rewarded with a number of connections allowing
them to acquire or offload valuables at market rates.
Merchant encompasses a number of different SubSkills which may be purchased in any order so long
as the Character meets all prerequisites for the
chosen Sub-Skill.

 Each Rank in this Skill a Character has grants
them a single Merchant Ticket. These tickets may be
used to enter special Merchant only draws for item
lots. A Merchant may place any number of their
tickets into any draw. These tickets are usable only
for the event they are issued and cannot be given
away or used by any other Character. The contents
of, and number of draws available at an Event is at
the discretion of the Marshal.

### Apothecary
**Prerequisites:** None\
**Benefit:** This Skill grants the Character the ability to
[Identify](/docs/invocations/invocation_descriptions/identify) Potions and Poisons which are not in a living
target. This ability takes sixty(60)-seconds to use on
any number of targets the Character is holding.
Additionally, if the Character has the Sense Poison
Skill, they can also use this Skill to [Identify](/docs/invocations/invocation_descriptions/identify) Poisons
present in living creatures.

### Appraiser
**Prerequisites:** None\
**Benefit:** This Skill allows the Character to accurately
determine the coin value of Trinkets. A Trinket is any
Game Item which has a measurable value, usually of
at least one(1) gold piece.

### Banker
**Prerequisites:** Read & Write\
**Benefit:** This skill grants the character the ability to
invest their money to gain interest. Any money the
character has in the Bank gains one percent(1%)
interest each month. Additionally, the Character may
issue withdrawals or deposits to the Royal Bank
during an Event.

### Chandler 
**Prerequisites:** None\
**Benefit:** This skill grants the character knowledge of
candle making. Once per Day, they may perform a
five(5) minute ceremony involving the creation of a
number of candles equal to the number of candles for
which they have [Physical Representations](/docs/equipment). Once
created, any Character may expend the created
candle to deliver a single “Activate: [Physical](/docs/glossary/delivery-types#physical) Lantern”
effect.

Additionally, once per year, the Character may
create an exceptionally well made candle with a value
of at least one-hundred(100) gold pieces. This item is
Legendary and can be used in the creation of an
eight(8) Ritual effect item. The Character must
expend an amount of gold equal to the value of the
item.

### Chef
**Prerequisites:** None\
**Benefit:** Once per Event, a Character with this skill
may prepare an exceptionally fortifying meal which
grants all who consume it five(5) additional Hit Points
until the end of the Day. Additionally, they may, once
per Day, create a meal which grants all who consume
it five(5) [Fortification Points](/docs/glossary/fortify). Each additional
Character with the Chef Sub-Skill increases the
number of Hit Points, or [Fortification Points](/docs/glossary/fortify) by one(1).
A Character can never gain more than ten(10) Hit
Points from this ability.

### Fence
**Prerequisites:** Appraiser\
**Benefit:** This skill grants the Character the ability to
increase the amount of coin gained from selling items
to the Merchant’s Guild by ten(10%) percent. This
Skill cannot be used on any Player created Trinkets.

### Jeweller
**Prerequisites:** None\
**Benefit:** This skill allows the Character to create
Trinkets with a value of ten(10), or more, gold pieces.
These items are Mastercrafted and are valid targets
for Ritual effects. Additionally, once per year, the
Character may create an exceptionally well made
piece of jewellery with a value of at least onehundred(100) gold pieces. This item is Legendary
and can be used in the creation of an eight(8) Ritual
effect item. The Character must expend an amount of
gold equal to the value of the item.

### Leatherworker
**Prerequisites:** None\
**Benefit:** This skill allows the Character to create
leather Trinkets with a value of ten(10), or more, gold
pieces. These items are Mastercrafted and are valid
targets for Ritual effects. Additionally, once per year,
the Character may create an exceptionally well made
piece of leatherwork with a value of at least onehundred(100) gold pieces. This item is Legendary
and can be used in the creation of an eight(8) Ritual
effect item. The Character must expend an amount of
gold equal to the value of the item.

### Locksmith
**Prerequisites:** None\
**Benefit:** The Character may, if they have a set of
lockpicks, attempt to open any in-game lock. If no
lock is present, the Character needs to role-play the
process as a sixty(60)-count.

 If the Character has the Open Lock Skill, they
reduce the time needed to open a lock to ten(10)
seconds. If the lock has a limited number of tries,
they gain one(1) additional attempt.

 Additionally, this skill allows the Character to create
locking Trinkets, such as locks, sealed containers and
chests, with a value of ten(10), or more, gold pieces.
These items are Mastercrafted and are valid targets
for Ritual effects. Additionally, once per year, the
Character may create an exceptionally well made
lock work with a value of at least one-hundred(100)
gold pieces. This item is Legendary and can be used
in the creation of an eight(8) Ritual effect item. The
Character must expend an amount of gold equal to
the value of the item.

### Tailor

**Benefit:** This skill allows the Character to create cloth

once per year, the Character may create an
exceptionally well made piece of clothing with a value

Legendary and can be used in the creation of an

### Textiles Artist
**Prerequisites:** None\
**Benefit:** This skill allows the Character to create
woven Trinkets, such as rugs, flags and tapestries,
with a value of ten(10), or more, gold pieces. These
items are Mastercrafted and are valid targets for

### Tinkerer
**Prerequisites:** None\
**Benefit:** This skill grants the character knowledge of
proper journeyman repair techniques. Characters
with this skill may [Repair](/docs/glossary/repair) Broken objects made of
Steel at a forge, as per the Smithing skill. If a
character possesses this skill and Field Mend in the
Smithing skill, then they can repair two(2) Mastercraft
items instead of one(1).

 Additionally, if the Character possesses the Skill
Field [Repair](/docs/glossary/repair), they may use its ability twice before
needing to Rest.
