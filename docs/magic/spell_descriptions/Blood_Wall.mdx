# Blood Wall
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet, Multiple<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell can be used for one of two(2) effects. The first causes twenty(20) points of [Piercing](/docs/glossary/delivery-types#piercing) [Magic](/docs/glossary/delivery-types#magic) [Body](/docs/glossary/body) damage to the target. The second causes twenty(20) points of Piercing Magic [Healing](/docs/glossary/healing) to the target. In either case, the Caster must expend eight(8) Hit Points to cast this Spell. The Caster may throw any number of packets when using this Spell and any creature struck by one or more packets is affected.

 If this Spell is affected by the [Echo](/docs/glossary/echo) [Spellshape](/docs/magic/spellshapes) effect the caster must expend the Hit Points again for each time the effect is duplicated.

 If this Spell is affected by the [Empower Spellshape](/docs/skills/magic-skills/empower-spellshape) effect the caster must instead expend twice the number of Hit Points the Spell normally requires.

 If this Spell is placed in a [Diagnose](/docs/skills/crafting-skills/potion) or [Diagnose](/docs/skills/crafting-skills/scroll), the Caster must choose which of the two(2) effects are contained within the crafted item.<br/>
<b>Incantation:</b> "I Conjure a Blood Wall."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "20 [Piercing](/docs/glossary/delivery-types#piercing) [Magic](/docs/glossary/delivery-types#magic) [Body](/docs/glossary/body)" or "20 Piercing Magic [Healing](/docs/glossary/healing)"<br/>
