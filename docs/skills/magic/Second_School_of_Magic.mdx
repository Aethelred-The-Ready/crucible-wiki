# Second School of Magic
<b>Requirements:</b> [First School of Magic](/docs/skills/magic/First_School_of_Magic.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character access to their second School of [Magic](/docs/glossary/delivery-types#magic). The Character is able to expend their Spell Slots to use the Spells which belong to any schools they know. See [Spellcasting](/docs/magic/spellcasting) for more information on the Schools of Magic.<br/>
