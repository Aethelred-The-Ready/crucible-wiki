# Metal Dust
<b>Type:</b> Smithing<br/>
<b>Duration:</b> Reset<br/>
<b>Effect:</b> This Invocation grants the Caster five(5) Charges. The Caster may expend one(1) Charge in order to deliver, by [Contingency](/docs/glossary/delivery-types#touch), an &lt;[Iron](/docs/equipment/special-materials), Normal, or Silver&gt; [Aura](/docs/glossary/aura) effect allowing the target to use the chosen Weapon Type against a single opponent until end of Combat.<br/>
