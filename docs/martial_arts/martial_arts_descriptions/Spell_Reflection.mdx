# Spell Reflection
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Artistry causes the next effect, delivered as [Magic-Strike](/docs/glossary/delivery-types#magic), by which the target is struck, to rebound against its Caster. The call for this effect, when triggered, is "[Reflect](/docs/glossary/reflect)".<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Reflect](/docs/glossary/reflect) [Magic](/docs/glossary/delivery-types#magic)"<br/>
