# Third Martial Arts School
<b>Requirements:</b> [Second Martial Arts School](/docs/skills/fighting/Second_Martial_Arts_School.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character access to their third Martial Arts School. The Character is able to expend their Martial Arts Slots to use the Martial Arts which belong to this school, and any other School the Character knows. See [Spellcasting](/docs/magic/spellcasting) for more information on Martial Arts.<br/>
