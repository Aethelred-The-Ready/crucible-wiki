# Piercing Spell
<b>Requirements:</b> Level 7 [Spell Slot](/docs/new_skills/magic/Spell_Slot.mdx)<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a single Spell, with a Range of Packet, as [Piercing](/docs/glossary/delivery-types#piercing). The call for this ability is "&lt;Incantation&gt; &lt;#&gt; Piercing &lt;Delivery Type&gt; &lt;Effect&gt; &lt;Option&gt;". For example, a [Sleep](/docs/glossary/compulsion#sleep) Spell would use the Delivery Verbal "Piercing [Magic](/docs/glossary/delivery-types#magic) Sleep" while an [Elemental](/docs/glossary/delivery-types#elemental) Bolt would use the Delivery Verbal "10 Piercing Elemental &lt;Type&gt;".<br/>
