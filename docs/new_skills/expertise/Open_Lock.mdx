# Open Lock
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character may, if they have a set of lockpicks, attempt to open any in-game lock. If no lock is present, the Character needs to role-play the process as a sixty(60)-count. This Skill can also be used to disarm, and [Destroy](/docs/glossary/destroy) a Trap. The Character needs to role-play the process as a sixty(60)-count. If the Character has the Locksmith Sub-Skill of the Merchant Background Skill, they reduce the time needed to open a lock to ten(10) seconds. If the lock has a limited number of tries, they gain one(1) additional attempt. If the Character has the Spy Background Skill, they reduce the time needed to disarm a trap to ten(10) seconds. If the Trap has a limited number of tries, they gain one(1) additional attempt.<br/>
