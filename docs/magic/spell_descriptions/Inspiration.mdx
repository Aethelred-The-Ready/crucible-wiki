# Inspiration
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell allows the target to instantly recover a single expended Skill Slot. A target can benefit from this effect no more than once per Reset regardless of its source.<br/>
<b>Incantation:</b> "I call upon the Dawn to Inspire you."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Inspiration](/docs/glossary/inspiration)"<br/>
