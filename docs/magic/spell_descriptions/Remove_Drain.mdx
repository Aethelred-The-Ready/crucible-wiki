# Remove Drain
<b>School:</b> [Restoration](../restoration_list)<br/>
<b>Level:</b> 5<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell removes, from the target, the [Drain](/docs/glossary/curse#drain) effect. Since a target cannot have multiple instances of the same effect, this removes all Drains from the target.<br/>
<b>Incantation:</b> "I call upon the Dusk to Remove Drain."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Remove](/docs/glossary/remove) [Drain](/docs/glossary/curse#drain)"<br/>
