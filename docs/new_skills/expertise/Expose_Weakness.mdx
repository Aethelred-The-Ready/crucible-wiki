# Expose Weakness
<b>Requirements:</b> [Stealth Training](/docs/new_skills/expertise/Stealth_Training.mdx) 1 per Rank<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought the Character may grant themselves the effects of an [Ambush](/docs/glossary/ambush) 5, allowing them to use their damage bonus from Stealth Training, for their next five(5) landed hits, even if they aren't behind their target. The call for this ability is "[Physical](/docs/glossary/delivery-types#physical) Ambush 5". Additionally, if the Character has exhausted all uses of this Skill for the current Reset period, the character may Rest in order to recover a single use of this Skill.<br/>
