# Escape Binding
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a "[Physical](/docs/glossary/delivery-types#physical) [Dispel](/docs/glossary/dispel) [Binding](/docs/glossary/binding)" effect on themselves on a three(3)-count. The call for this ability is "I rip free 1, I rip free 2, I rip free 3. Physical Dispel Binding."<br/>
