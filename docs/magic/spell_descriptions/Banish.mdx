# Banish
<b>School:</b> [Conjuration](../conjuration_list)<br/>
<b>Level:</b> 9<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell forces the target Extraplanar creature or [Elemental](/docs/glossary/delivery-types#elemental) back to its home plane. A creature which has been affected by this effect cannot return to the plane from which it was Banished for twenty-four(24) hours.

 This Spell only functions on Hymira and will fail if cast on any other Plane.<br/>
<b>Incantation:</b> "I Conjure a force to Banish."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) Banish"<br/>
