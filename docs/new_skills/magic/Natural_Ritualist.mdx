# Natural Ritualist [Heritage, Magical]
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character may participate in the casting of Ritual [Magic](/docs/glossary/delivery-types#magic) as a Secondary Caster. This does not grant the Character the ability to cast any Rituals, only add one(1) to the count of total casters. If the Character also has the Skill Ritual Magic, the number of Casters the Character counts as is increased by one(1). This Skill does not increase the number of Invocations a Character can cast per Reset.<br/>

Category: [Magic](.)
