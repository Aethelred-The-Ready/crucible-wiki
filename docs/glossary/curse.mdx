# Curse

Curse effects have a variety of different effects such
as preventing the target from using Skills, causing
them to take more damage, or immobilising them
completely. are those which affect the target's mind
and can be defended against, or [Removed](./remove), by
abilities which are applicable against Curse effects or
the [Delivery Type](./delivery-types) used to deliver the Curse effect.

### Blind
This Curse effect prevents the target from using
any ranged attacks including thrown weapon and packet
attacks.

### Cripple
This Curse effect affects a limb of the
target. A Crippled arm cannot be used for any Skills
and cannot hold any items. A Crippled leg cannot be
used to walk and prevents the target from moving
faster than a slow, limping walking pace. The target
cannot hop. If both legs are Crippled the target can
only kneel in place. Unlike most effects, this one
stacks with each new Cripple effect affecting a new
limb until the Character has no remaining limbs

### Drain
This Curse effect prevents the target from
running or using any Skills until the effect ends or is
removed.

### Frailty
This Curse effect causes the target to take
double damage from all effects. Additionally, the
Character cannot use any form of the Defensive
Ability Resist.

### Fetter
This Curse effect prevents the target from running,
jumping, or moving faster than a normal walking
pace.

### Fumble
This Curse effect prevents the
target from using the named weapon for any Skills.
The weapon cannot be used to attack or even block
weapon attacks. This effect lasts ten(10) seconds.

### Paralysis
This Curse effect completely immobilises
the target preventing them from speaking, moving, or
using any Skills. This effect does not prevent the target
from being moved, and may be carried. While under this
effect the player can choose if any forced motion results
in their pose being changed and maintaining the new
pose, or having any attempt result in them falling limp to
the ground.

### Weakness 
This Curse effect prevents the target
from using Martials Arts with a Range of Strike, or
Skills requiring the use of weapons except Weapon
Proficiencies. The target may still cast Alchemy or
Spells which are delivered as &lt;Delivery Type>-Strike.
