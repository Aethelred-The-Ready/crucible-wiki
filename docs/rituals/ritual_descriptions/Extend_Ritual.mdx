# Extend Ritual
<b>Cost:</b> P2 T2<br/>
<b>Type:</b> Alchemy, Magic, Smithing<br/>
<b>School:</b> All<br/>
<b>Target:</b> Ritual Concert<br/>
<b>Duration:</b> One(1) Year<br/>
<b>Effect:</b> When cast as the last Ritual in a Ritual [Concert](/docs/rituals/ritual_glossary#Concert), this Ritual extends the duration of all valid Ritual effects in the current target Ritual Concert to one(1) year. This effect does not count towards the number of Ritual Effects on an [Item](/docs/rituals/ritual_glossary#Item).<br/>
