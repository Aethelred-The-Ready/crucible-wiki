# Paralysis
<b>School:</b> [Affliction](../affliction_list), [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Curse](/docs/glossary/curse) Spell completely immobilises the target preventing them from speaking, moving or using any Skills while it is in effect. This effect does not prevent the target from being moved.<br/>
<b>Incantation:</b> "I Curse you with Paralysis."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Paralysis](/docs/glossary/curse#paralysis)"<br/>
