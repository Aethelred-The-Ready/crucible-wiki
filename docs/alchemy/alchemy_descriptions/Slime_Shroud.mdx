# Slime Shroud
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Charged (1)<br/>
<b>Effect:</b> This Alchemy grants the target a [Ward](/docs/glossary/Ward) allowing them to negate a single effect causing Weapon Damage, or delivered as [Physical-Strike](/docs/glossary/delivery-types#physical), by which they are struck. The target chooses when to activate this ability. When activated, this Alchemy also instantly restores any [Physical Armour](/docs/equipment/armour) the Caster possesses to full value. The call for this effect is "Ward, [Poison](/docs/glossary/delivery-types#poison) [Refit Physical Armour](/docs/glossary/refit)".<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Physical](/docs/glossary/delivery-types#physical) [Ward](/docs/glossary/Ward)"<br/>
