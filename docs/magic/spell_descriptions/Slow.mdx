# Slow
<b>School:</b> [Affliction](../affliction_list), [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Spell reduces the value of any [Avoidance Armour](/docs/equipment/non-physical-armour) worn by the target to zero(0).<br/>
<b>Incantation:</b> "I alter this form to be Slowed."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Breach](/docs/glossary/breach) [Avoidance Armour](/docs/equipment/non-physical-armour)"<br/>
