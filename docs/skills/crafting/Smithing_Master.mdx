# Smithing, Master
<b>Requirements:</b> [Smithing](/docs/skills/crafting/Smithing.mdx) 10<br/>
<b>Benefit:</b> A Character with this Skill may create Mastercraft Weapons and [Physical Armour](/docs/equipment/armour). These exceptional Weapons can also include rare and Special Materials such as Adamantine, [Iron](/docs/equipment/special-materials) and [Silver](/docs/equipment/special-materials).<br/>
