# Natural Parry
<b>Requirements:</b> None<br/>
<b>Benefit:</b> Once per Reset, the Character may negate any attack delivered, by weapon or packet, as [&lt;Effect&gt;- Strike](/docs/glossary/delivery-types#strike) or [Physical](/docs/glossary/delivery-types#physical) by which they are struck. The call for this ability is "Parry".

If the Character has the Bodyguard Skill they can use this ability to negate an applicable attack which strikes another target within their Weapon's reach. This Skill does not count as a prerequisite for any other Skill.<br/>
