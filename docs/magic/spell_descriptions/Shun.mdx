# Shun
<b>School:</b> [Affliction](../affliction_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This [Compulsion](/docs/glossary/compulsion) Spell prevents the target from willingly approaching the Caster or attacking the Caster. This effect ends if the Caster attacks the target.<br/>
<b>Incantation:</b> "I Compel you to Shun me."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Shun](/docs/glossary/compulsion#shun)"<br/>
