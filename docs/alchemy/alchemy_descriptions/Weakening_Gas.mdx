# Weakening Gas
<b>School:</b> [Alchemy](../alchemy_list)<br/>
<b>Level:</b> 3<br/>
<b>Range:</b> Packet<br/>
<b>Duration:</b> 5 Minutes<br/>
<b>Effect:</b> This Alchemy prevents the target from using Martial Arts with a Range of Strike, and Skills requiring the use of weapons, except Weapon Proficiencies. The target may still cast Spells which are delivered as &lt;Delivery Type&gt;-Strike.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Poison](/docs/glossary/delivery-types#poison) [Weakness](/docs/glossary/curse#weakness)"<br/>
