# Shield
<b>Requirements:</b> None<br/>
<b>Benefit:</b> The Character gains the ability to wield all [Shield](/docs/glossary/shield)s and the ability to use a single shield in combat. There is no way for a Character to wield more than one(1) Shield at once. For information of the requirements for the [Physical Representations](/docs/equipment) for this, and other Weapons, see Chapter 5: Equipment.<br/>
