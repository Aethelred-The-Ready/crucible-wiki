# Second Martial Arts School
<b>Requirements:</b> [First Martial Arts School](/docs/new_skills/fighting/First_Martial_Arts_School.mdx)<br/>
<b>Benefit:</b> This Skill grants the Character access to their second Martial Arts School. The Character is able to expend their Martial Arts Slots to use the Martial Arts which belong to this school, and any other School the Character knows. See Chapter 7: Magic for more information on Martial Arts.<br/>
