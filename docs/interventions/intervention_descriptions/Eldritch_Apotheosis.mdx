# Eldritch Apotheosis
<b>Type:</b> Magical<br/>
<b>Benefit:</b> This Intervention requires the Character to have access to the following Schools of [Magic](/docs/glossary/delivery-types#magic); Affliction, Conjuration, Protection, Restoration, and Transmutation. Upon performing this Intervention the character gains five(5) Charges of this ability. The Character may, when casting a Spell from memory, expend one(1) Charge of this ability to gain one of the following effects;

 Triplet Spell: The Character may deliver two(2) copies of the Spell. These copies include all the same [Spellshapes](/docs/magic/spellshapes) or options made when casting the Spell as per the Skill [Echo](/docs/glossary/echo) Spell except the Character may Echo the Spell Twice instead of only once.

 Intensify Spell: This ability can only be used on Spells with a Range of Packet or [Contingency](/docs/glossary/delivery-types#touch). The damage, or healing, caused by the Spell are quadrupled.

 [Arcane](/docs/glossary/delivery-types#arcane) Spell: This ability allows the Character to deliver a single Spell, below 9th Level, as Arcane(- Strike).

 Parallelisation: This ability can only be used on Spells with a Range of Packet or Touch. The Character may throw any number of packets to deliver the Spell. Any Character struck by one or more packets is affected by the effect. Alternatively, the Caster may deliver the Spell, by Touch, to any number of targets so long as no target receives the same effect more than once and no more than ten(10) seconds go by without the Character affecting a new target.

 Cyclical Magic: The Character recovers all Spells Slots which were expended to Cast Spells which benefited from the effects of this Intervention.

 Each ability can be used only once. No Spell may benefit from more than a single effect of this Intervention at a time. Any unused Charges are lost at the end of the current [Reset](/docs/glossary/reset) period.<br/>
