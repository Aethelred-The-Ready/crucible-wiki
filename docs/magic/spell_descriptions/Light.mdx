# Light
<b>School:</b> [Conjuration](../conjuration_list), [Restoration](../restoration_list), [Transmutation](../transmutation_list)<br/>
<b>Level:</b> 1<br/>
<b>Range:</b> Touch<br/>
<b>Duration:</b> Day<br/>
<b>Effect:</b> This Spell creates a magical light source which allows the use of a diffused flash light, lantern, glow stick or similar light source. A light source may be disqualified from use if it is too bright. The decision as to whether or not a light can be used is up to the Marshal.<br/>
<b>Incantation:</b> "I grant you the power of a Light."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Lantern](/docs/glossary/lantern)"<br/>
