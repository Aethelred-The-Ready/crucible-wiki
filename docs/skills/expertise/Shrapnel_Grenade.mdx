# Shrapnel Grenade
<b>Requirements:</b> See Text<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a Packet attack causing "50 [Physical](/docs/glossary/delivery-types#physical) Normal" damage to the target. Alternatively, the Character may expend a single use of this Skill in order to deliver a Packet attack which causes a &quot;20 Physical Silver&quot; damage or &quot;20 Physical Iron&quot; damage to the target.

A Character may also expend a single use of this Skill in order to deliver a Packet attack, delivered by any number of packets, which cause a "[Lesser](/docs/glossary/delivery-types#lesser) Physical [Fetter](/docs/glossary/curse#fetter)" to any Character struck by one or more packets.

This Skill requires the Character to have any combination of three(3) the following Skills; Acid Grenade, Fire Grenade, Freezing Grenade, or Toxin Grenade, for every time this Skill is bought.<br/>
