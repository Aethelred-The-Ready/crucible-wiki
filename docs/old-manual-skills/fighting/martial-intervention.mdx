# Martial Intervention
import Skill from '../skill.tsx'

<b>Requirements:</b> 20 Character Levels per Rank.\
This Skill allows the Character to perform an [incredible act of martial prowess](../../intervention) beyond the limits of what should be possible. A Character can have only one Intervention Skill for every twenty(20) Character Levels they possess. Each Intervention Skill allows the Character to perform one(1) Intervention per Event. These uses can never be recovered.
