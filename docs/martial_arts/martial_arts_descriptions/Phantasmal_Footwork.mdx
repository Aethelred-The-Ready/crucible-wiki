# Phantasmal Footwork
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 8<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Artistry grants the Caster a Dodge against the next three(3) effects, delivered by Weapon or Packet, by which it is struck. Unlike the [Dodge Skill](/docs/skills/expertise/dodge), the Caster does not choose when this ability activates, it is automatically triggered as soon as the Caster is struck by an applicable effect.<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Physical](/docs/glossary/delivery-types#physical) [Mirage](/docs/glossary/mirage) 3"<br/>
