# Composure
<b>School:</b> [Duelist](../duelist_list)<br/>
<b>Level:</b> 4<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry causes twenty(20) points of [Physical](/docs/glossary/delivery-types#physical) [Healing](/docs/glossary/healing) to the Caster. Any healing above the Character's maximum is converted into [Fortification Points](/docs/glossary/fortify).<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "20 [Physical](/docs/glossary/delivery-types#physical) [Healing](/docs/glossary/healing)"<br/>
