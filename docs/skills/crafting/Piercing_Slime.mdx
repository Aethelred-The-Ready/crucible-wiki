# Piercing Slime
<b>Requirements:</b> Level 7 Alchemy Slot<br/>
<b>Benefit:</b> Once per Reset, for every time this Skill is bought, the Character may deliver a single Alchemy, with a Range of Packet, as [Piercing](/docs/glossary/delivery-types#piercing). The call for this ability is "&lt;#&gt; Piercing &lt;Delivery Type&gt; &lt;Effect&gt; &lt;Option&gt;". For example, a [Sleep](/docs/glossary/compulsion#sleep) Alchemy would use the Delivery Verbal "Piercing [Poison](/docs/glossary/delivery-types#poison) Sleep" while an Alchemist's Flask would use the Delivery Verbal "10 Piercing Poison &lt;Type&gt;"<br/>
