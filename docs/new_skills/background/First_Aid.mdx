# First Aid
<b>Requirements:</b> None<br/>
<b>Benefit:</b> This Skill allows the Character to [Stabilise](/docs/glossary/stabilise) a Dying target. In order to use this Skill, the Character must touch the target and state "First Aid". If the target is not Dying, or immune to First Aid, the target must immediately state "No Effect". Applying First Aid is a sixty(60) second Counted Action. Once First Aid has begun, the target immediately pauses their Dying Count. it remains paused until either the First Aid count is finished, or interrupted. In the latter case the dying creature immediately resumes their count where it left off. At the end of the First Aid count, the target is Stabilised and at zero(0) Hit Points. After one(1) minute the target regains Consciousness at one(1) Hit Point. This Skill is modified by the Physician Background Skill. For more information on how these Skills interact, See page 203.<br/>
