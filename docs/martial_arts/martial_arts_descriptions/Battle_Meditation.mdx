# Battle Meditation
<b>School:</b> [Duelist](../duelist_list), [Guardian](../guardian_list), [Slayer](../slayer_list)<br/>
<b>Level:</b> 7<br/>
<b>Range:</b> Self<br/>
<b>Duration:</b> Instant<br/>
<b>Effect:</b> This Artistry instantly grants the target the benefits of having Meditated. This applies only to expended Skills which are recovered by Meditating.<br/>
