# Imprison

This effect encases the target in a
magical field preventing them from speaking, moving,
being moved, or using any Skills. While inside the
Imprison, the target is immune to all effects except
Dispel &lt;Delivery Type of Imprison&gt; which removes
this effect. The caster may also end the Imprison
effect by simply touching the target and stating
“Imprison down”. If the caster is also the target they
may expend one use of the Skill Harden Magic to
negate a single [Dispel](/docs/glossary/dispel) [Magic](/docs/glossary/delivery-types#magic) effect from removing the Imprison.

The caster can also use the Imprison to deliver a [Killing Blow](/docs/glossary/killing-blow), which counts as Magic, upon the target. To do so the
caster must touch the target and state “Killing Blow 1,
Killing Blow 2, Killing Blow 3, Magic”
