# Seal Container
<b>School:</b> [Protection](../protection_list)<br/>
<b>Level:</b> 2<br/>
<b>Range:</b> Container<br/>
<b>Duration:</b> Indefinite<br/>
<b>Effect:</b> This Spell prevents the target container from being opened by anyone but the Caster. Once the Caster opens the target container this effect ends. The Container targeted by this ability must be marked with an "S".<br/>
<b>Incantation:</b> "I grant you the Protection of a Sealed Container."<br/>
<b>[Delivery Verbal](/docs/glossary/delivery-verbal):</b> "[Magic](/docs/glossary/delivery-types#magic) [Seal](/docs/glossary/seal) Container"<br/>
