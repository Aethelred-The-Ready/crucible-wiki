# Talon Rake
<b>Cost:</b> P4 D3 S2<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Restoration](/docs/magic/restoration_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Claw<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual effect grants the target Claw with the following effect. One per [Reset](/docs/glossary/reset), the Character may use the Claw to deliver an attack which causes [Body](/docs/glossary/body) Damage instead of its usual Weapon Type. This includes Martial Arts which normally cause Weapon Type damage as well as normal Weapon Damage attacks.<br/>
