# Thundering Strike
<b>Cost:</b> P4 C2 D2 T1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Affliction](/docs/magic/affliction_list), [Conjuration](/docs/magic/conjuration_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Two-Handed Weapon<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> Once per [Reset](/docs/glossary/reset), the wielder of this Weapon may use it to deliver an attack causing "50 Physical- Strike &lt;Weapon Type&gt;". The Weapon Type of this effect is determined by the Weapon Type of the Weapon used to deliver the attack.<br/>

This Ritual can be cast on a target more than once
