# Enhance Armour
<b>Cost:</b> P2 C1 S1<br/>
<b>Type:</b> Magic, Smithing<br/>
<b>School:</b> [Protection](/docs/magic/protection_list), [Transmutation](/docs/magic/transmutation_list)<br/>
<b>Target:</b> Any Physical Armour<br/>
<b>Duration:</b> Event<br/>
<b>Effect:</b> This Ritual increases the Armour Points granted by the target suit of [Physical Armour](/docs/equipment/armour) by two(2) for each casting. For every ten(10) additional points of armour, or portion thereof, this effect counts as one(1) effect towards the item's Ritual Effect Limit.<br/>

This Ritual can be cast on a target more than once
